# 设计

- Memory 是 BAGEL 在单个采样状态内部的语义工作空间。
- 理解专家 UND 把文本与当前生成状态写入 Memory，生成专家 GEN 读取 Memory，并把结果变成图像速度。
- BAGEL 本体保持冻结（暂定）。学习写入残差和视觉读取残差，分别在第 3–6 节训练。

实验设置、对照臂与结果见[实验记录](experiments.md)。

## 1. 动机

文生图的计算通常加在两条外路上：加大网络，或增加采样步数。每增加一步，都要在新的 $(x_t, t)$ 上完整跑一次去噪网络。下面两篇工作把额外计算放进同一次去噪调用，latent、时间和条件先保持不动，外层采样器之后再推进。

[Looped-DiT](https://arxiv.org/abs/2609.40305)（Chng 等，2026）在每个去噪步内重复一组共享的 Transformer block。网络分成环前、环内、环后三段。环内参数跨轮共享，轮数增加计算深度，参数量和序列长度保持不变。循环发生在采样器推进之前，因此环深和外层步数可以分开调节。他们的观察是：直接重复共享层并不可靠。只监督最后一轮时，前面各轮缺少直接梯度；不受调节的注意力更新会逐步冲掉图像 token 里的局部信息，patch 坐标的线性可解码性随轮数下降。Looped-DiT 用两条训练措施稳住循环：每一轮隐状态都经过共享的环后段，对同一个 flow 目标做深度监督；环内注意力按当前隐状态调节更新幅度。在相同推理预算下，增加环深比增加去噪步收益更大，后续轮次会修正前面轮次的内容、空间和多余物体。

[Training-Free Hidden-State Refinement](https://arxiv.org/abs/2608.29160)（Yan 等，2026）把同一思想用到已经冻结的 flow-matching 生成器上。权重和外层采样器保持原样。额外计算来自在选定的层段、采样进程区间和 token 范围内重复层计算，并用每轮强度控制残差大小。采样进程门控决定哪些外层步骤启用循环，层段决定在网络的哪一段循环。Loop Guidance 再把普通速度和循环速度合成为实际采样速度。这篇工作说明冻结生成器内部可以分配推理计算。它重复的是去噪器自己的隐状态，理解与生成的条件交换仍走原有文本 K/V。

BAGEL 已经把理解与生成分成 UND 和 GEN 两个专家，两者通过文本预填充的逐层 K/V 交换条件。

内层循环固定 $(x_t, t, \text{prompt})$，外层采样器只消费最终速度。循环状态是一份独立的 16 槽 Memory。UND 负责生成memory，从当前生成状态（含噪声）获得反馈，GEN 负责读 Memory 并给出速度。冻结骨干对应训练自由工作的约束；每一轮出口都接受监督，对应 Looped-DiT 对中间循环给直接学习信号的结论。重复写入由零初始化的低秩残差调节，避免更新幅度在训练开始时改写中性起点。

由此得到两个可训练接口：


| 接口               | 推理中的位置         | 训练                        |
| ---------------- | -------------- | ------------------------- |
| 写入低秩残差           | 每一层 UND 更新之后   | 第 3 节建立表达，第 4 节使 GEN 能消费它 |
| 时间条件的视觉 query 残差 | UND 读取 GEN 来源时 | 第 5 节；第 6 节纳入联合目标         |


GEN、UND 骨干、VAE 和采样器保持原参数。第 4 节和第 6 节通过冻结 GEN 的注意力响应和速度，把梯度送回上述残差。

## 2. 推理框架



### 2.1 两层循环

外层按 flow 时间推进 latent。内层在一个时间状态上反复读写 Memory。内层期间，带噪 latent $x_t$、噪声时间 $t$ 和 prompt 保持不变。

本仓库的 flow 约定是

$$
x_t=(1-t)x_0+t\epsilon,\qquad v^*=\epsilon-x_0.
$$

从时间 $t$ 走到下一时间 $s$ 时，Euler 更新使用引导后的速度：

$$
x_s=x_t-(t-s)v_{\mathrm{CFG}}.
$$

$v_{\mathrm{CFG}}$ 由条件分支和原生无条件分支组成。Memory 进入条件分支。无条件分支沿原生 GEN 计算，给 CFG 提供参照速度。

一个内层循环的信息角色如下。


| 对象             | 由谁计算                   | 作用                        |
| -------------- | ---------------------- | ------------------------- |
| Prompt 的逐层 K/V | 冻结 UND 预填充，每个采样过程计算一次  | 原生文本条件，内层循环中保持不变          |
| GEN 逐层 K/V     | 冻结 GEN 处理当前 $x_t$        | Memory 的来源，携带图像状态、时间和已有条件 |
| Memory 逐层 K/V  | 冻结 UND 加可训练残差          | 独立语义条件，供 UND 读出和 GEN 消费   |
| 条件速度           | 冻结 GEN 读完 Memory 后的输出头 | 内层循环的生成结果，外层用它推进 latent   |



### 2.2 UND 与 GEN 的计算角色

两套专家共用注意力接口，计算内容不同。

#### 2.2.1 UND

- prompt 预填充把用户文本变成逐层 K/V，此后作为 GEN 的固定上下文。
- writer 用同一套冻结 UND block 更新 Memory：query 读取同层来源(prompt+GEN hidden)和 Memory 自身，输出新的 Memory hidden，并导出该层 K/V。
- 文本读出时，冻结 UND 以 Memory、固定描述指令和已生成词为上下文，逐词产生 caption。caption 用于观察 Memory 中的语义，采样速度由 GEN 出口给出。



#### 2.2.2 GEN

- 在当前 $x_t$ 上计算来源。图像 token 和边界 token 走各自的原生 GEN 投影、归一化和 RoPE，得到该层 query 的 K/V。Prompt 的 K/V 留在缓存中，来源只含当前 query。
- 消费 Memory。条件分支的键和值按同一顺序拼接：

$$
K=[K_{\mathrm{prompt}};K_{\mathrm{Memory}};K_{\mathrm{image}}],\qquad
V=[V_{\mathrm{prompt}};V_{\mathrm{Memory}};V_{\mathrm{image}}].
$$

图像 query 的位置整体后移 16，给 Memory 留出位置。随后的专家投影、归一化、后续层和速度头仍是原生 GEN。Memory 的作用经过整张生成网络传到 $v_{\mathrm{cond}}$。

因此一次反馈里，GEN 先把当前图像状态变成来源，UND 把来源写成 Memory，GEN 再把 Memory 读回新的生成状态。速度由 GEN 输出头给出，Memory 由 UND writer 导出。

### 2.3 Memory 初始化

Memory 从一句固定中性文本的因果 UND 预填充开始。预填充只编码这句文本，由冻结 UND 完成。每一层留下一份 hidden，称为中性seed。所有样本、所有反馈轮次共用这组种子，样本差异只从来源 K/V 进入。

Writer 使用连续更新：第 0 层从第 0 层种子出发，之后每一层接收上一层更新后的 hidden。槽位数为 16。Writer 自己的 RoPE 位置从 2048 起，与 prompt 和图像 token 的位置分开。

初始化由配置固定：中性文本、16 个槽和起点位置在训练期间保持不变，这里不引入可训练参数。

### 2.4 连续更新

设 $H_l$ 为第 $l$ 层 Memory hidden，$S_l$ 为其他条件，$F_l$ 为冻结 UND block，$A_l$ 为该层低秩残差：

$$
U_l=F_l(H_l;S_l),\qquad H_{l+1}=U_l+A_l(U_l).
$$

$F_l$ 先对 Memory hidden 做输入归一化，用 UND 的 Q/K/V 投影得到 query 和自身的键值，再与已经带有来源 RoPE 的 $S_l$ 做一次注意力，然后经过输出投影和 MLP。$A_l$ 是降维到秩 32 再升回原宽度的线性残差，升维矩阵初始化为 0。训练第 0 步时 $A_l$ 的输出为 0，Memory 的导出与中性种子经过冻结投影的结果一致。

更新后的 $H_{l+1}$ 再经过同层 UND 归一化和 K/V 投影。`MemoryBank` 保存的是未加 RoPE 的 K/V。文本读出和 GEN 消费时，各自按自己的序列位置旋转一次。这样同一份表达可以放在描述指令之前，也可以放在 prompt 与图像 query 之间。

来源有两种，写入公式相同：


| 来源  | $S_l$                           | 读取时的可训练部分                                |
| --- | ----------------------------- | ---------------------------------------- |
| 文本  | caption 的原生 UND 预填充 K/V       | 只有 $A_l$，训练见第 3、4 节                        |
| 视觉  | 当前 $x_t$ 上 GEN 第 $l$ 层的 query K/V | 时间条件 query 残差，训练见第 5、6 节；$A_l$ 默认沿用第 3、4 节 |


视觉读取在 UND 的 query 投影上加一项残差。它由 hidden 的低秩投影和时间特征相加，再升回 query 宽度。时间特征是 $\pi t$ 的正弦和余弦。升维矩阵同样初始化为 0。该项让同一套冻结 UND 在不同噪声水平上改变读取方式，GEN 的键、值和 RoPE 保持原生计算。视觉写入时，这个残差加在每一层 query 上，训练见第 5、6 节。来源窗口另行决定哪些层把 GEN K/V 并入注意力。浅层推理里，0–7 层读取本遍 GEN 来源，8–27 层只对 Memory 自身做注意力，hidden 仍逐层下传。

$A_l$ 负责 Memory 的表达，视觉 query 残差负责 UND 从来源中读取的方式。两组参数都在 Memory 分支上。某一组放开训练时，梯度穿过冻结的 $F_l$ 与冻结的 GEN 回到该组。

### 2.5 同状态反馈

第 $r$ 轮从中性种子重写 Memory。writer 的输入是中性种子、上一轮 GEN 来源和时间：

$$
M^{(r)}=\operatorname{Writer}(H_{\mathrm{neutral}}, S^{(r-1)}, t),
$$

$$
(S^{(r)}, v^{(r)})=\operatorname{GEN}(x_t, t, p; M^{(r)}).
$$

$S^{(0)}$ 来自尚未拼接 Memory 的条件 GEN。此后每一轮 GEN 都读取刚写好的 Memory，并把更新后的逐层状态交给下一轮 writer。最终一轮的 $v^{(R)}$ 进入 CFG，成为外层使用的条件速度。

推理时的计算分配沿用第 1 节的两个控制量。层窗口决定哪些 GEN 层重复产生来源：当前文生图入口重复 GEN 的第 0–7 层，每遍从同一入口 hidden 重新计算；UND writer 仍从中性种子走完全部层，其中 0–7 层读取本遍 GEN 来源，8–27 层继续自注意力。最后一遍才把 GEN 的 28 层完整运行一次，并读取最终 Memory。采样窗口决定哪些外层步骤启用上述反馈。窗口内的步骤执行多遍浅层 GEN 和相应次数的 Memory 重写；窗口之后的步骤沿原生 GEN 推进。R2、R3、R4 表示浅层 GEN 总共运行 2、3、4 遍，对应 1、2、3 次从中性种子开始的重写。

训练使用的闭环与这条推理同构，深度不同。C3 在完整 28 层上做两轮：原生来源写出第一份 Memory，GEN 消费后再写第二份。每一轮的 Memory 和条件速度都进入第 6 节的损失。轮与轮之间默认截断来源梯度，每一轮 writer 直接对本轮来源学习。

### 2.6 训练所对应的接口


| 推理中的计算                                             | 参数       | 谁来定它的内容                                          |
| -------------------------------------------------- | -------- | ------------------------------------------------ |
| 中性种子、prompt 预填充、UND block、GEN 投影与速度头、VAE、CFG 无条件分支 | 冻结       | 配置固定                                             |
| 每层 $A_l(U_l)$                                        | 写入低秩残差   | 第 3 节用 caption 恢复；第 4 节用 GEN 注意力响应继续适配；视觉阶段可保持冻结 |
| 视觉来源上的 query 增量                                    | 时间条件低秩残差 | 第 5 节只学语义读出；第 6 节同时接受响应和速度                       |
| $M$ 被冻结 GEN 读成 $v_{\mathrm{cond}}$                     | 无额外参数    | 第 4 节对齐教师条件的注意力输出；第 6 节对齐配对 flow 速度              |
| 第 2 轮及以后的 $M^{(r)}$、$v^{(r)}$                          | 沿用上面的残差  | 第 6 节对每一轮出口给监督                                   |



## 3. 文本写入

第 2.4 节的 $A_l$ 首先在文本接口上学习。文本预填充是 BAGEL 两侧已经使用的条件，用它作来源，可以把“来源 K/V 进入 Memory”和“Memory 被 UND 读回语言”先建立起来。

Writer 读取 caption 的逐层 K/V，从中性种子连续写出 16 槽 Memory。冻结 UND 再以该 Memory 和固定描述指令为条件，预测 caption 的下一个词。记目标文本为 $y$，指令为 $I$：

$$
L_{\mathrm{cap}}=-\mathbb{E}_j\log P_{\mathrm{UND}}(y_j\mid M,I,y_{<j}).
$$

教师强制给出因果的答案前缀。此损失只训练 $A_l$。它让低秩残差把冻结 UND 的隐状态移到可被语言接口恢复的区域。

进入这项训练之前，先用原生 UND 读取 caption 上下文并复述。这一步确认冻结文本接口本身保留对象、颜色、数量和关系，再把同样的读出接到 Memory 上。

## 4. 响应蒸馏

第 3 节确定 Memory 对 UND 表达什么。GEN 是否按文本条件的方式使用这 16 个槽，由同一组 $A_l$ 在本节继续学习。GEN 权重保持冻结。

在同一组 GEN query、同一份 prompt 与图像自身上下文中，比较两种附加条件的注意力输出。教师条件 $T_l$ 最初是 caption 的原生文本 K/V；文本 writer 训好之后，教师换成这份冻结 writer 压成的 16 槽 Memory。学生条件是当前 Memory。两者与共同上下文 $B_l$ 进入同一次 softmax：

$$
O_l^T=\operatorname{Attn}(Q_l,B_l\cup T_l),\qquad
O_l^M=\operatorname{Attn}(Q_l,B_l\cup M_l).
$$

读出固定在第 0、13、27 层。连续 hidden 把第 27 层的梯度送回前面每一层 $A_l$，第 0 层和第 13 层再提供中间读出。损失是学生输出相对教师输出的归一化均方误差，并与 $L_{\mathrm{cap}}$ 一起优化，使消费训练同时维持文本表达。图像 query 预先留出与槽位数相同的位置，probe 与正式 GEN 消费使用同一套位置安排。

## 5. 视觉读取

第 2.4 节的视觉 query 残差在这里学习。来源从文本预填充换成 GEN 对当前 $x_t$ 的逐层 K/V。$x_t$ 由配对干净图像和已知噪声按第 2.1 节的公式合成，学生侧的生成 prompt 使用固定的中性短句。来源因此同时含有图像状态、噪声时间和中性 prompt 的影响，目标描述留在监督文本里。

写入仍从中性种子开始，并经过全部 UND 层。视觉 query 残差按实际 $t$ 调制每一层 query。视觉阶段默认冻结文本阶段得到的 $A_l$，让它继续提供已学会的语义表达；此阶段的新参数是各层视觉残差。

监督仍是第 3 节的读出形式。描述指令随标签角色变化：目标描述要求恢复配对图像的内容，观察描述要求只陈述当前噪声证据支持的内容，差异描述要求比较目标与当前证据。默认的观察训练使用目标描述，让 Memory 从当前生成状态中组织可恢复的图像语义。此阶段的响应项和速度项权重为 0，先确认来源读取本身能进入语言接口。

## 6. 联合目标与多轮监督

视觉残差能够形成可读写的 Memory 之后，第 2.5 节的反馈才进入训练。优化对象仍是第 2.6 节列出的残差。C2-joint 训练一轮写入和一次 GEN 消费；C3-loop 在同一 $(x_t,t)$ 上训练两轮，对每一轮的 Memory 和出口速度都给损失。这对应第 1 节中对中间循环直接监督的安排：每一轮出口经过冻结 GEN 得到自己的速度，梯度直接回到该轮 writer。

四项损失分开加权：


| 项    | 计算                                  | 作用于                   |
| ---- | ----------------------------------- | --------------------- |
| 语义   | 第 3 节的 caption 负对数似然，对每轮 Memory 取平均 | Memory 能否读回目标描述       |
| 响应   | 第 4 节的归一化注意力误差；教师为冻结的 16 槽文本 Memory | GEN 读取方式是否接近已学会的文本条件  |
| 速度   | $\|v_{\mathrm{cond}}-v^*\|^2$，对每轮出口取平均 | Memory 是否改变完整生成网络的速度 |
| 文本保持 | 用文本来源重写 Memory，同时计算语义和响应            | 已有文本写入与读出             |


速度损失的梯度经过冻结 GEN 的后续层、归一化和输出头，回到被本阶段放开的残差。文本保持以一定比例替换视觉样本，写入时关闭视觉 query 残差，用来维持第 3、4 节已经形成的文本接口。

观察标签默认进入语义项。若同时把它用作响应教师，需要单独确认该描述就是生成条件。差异标签要求来源 prompt 明确带有目标意图，并在配置里打开目标 prompt。
