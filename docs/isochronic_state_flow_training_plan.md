# 等时生成态编辑：直接开训方案

日期：2026-11-06。方案标识：`u15_isochronic_state_flow_v1`。

**决定：训练固定生成时间上的状态编辑算子，再由冻结原生 T2I 接续。先用现成高质量编辑对开训；训练期间生产 ODE 配对缓存和通用真实父轨迹样本，随后继续做接续分布适配。不设置 Gate 0，不把零训练 Oracle 实验作为开训条件。**

本文是下一版实现合同。代码已按本文重构为 `u15_isochronic_state_flow_v1`；本文没有启动训练。旧设计见[真实历史态上的选择性语义修复](selective_semantic_correction_plan.md)，既有结果见 [E1 记录](e1_20261105_results_and_training.md)。本文中的步数、学习率、比例是首轮工程选择，性能和速度均需由训练后的成图建立。

## 1. 研究问题和首版范围

生成中途收到编辑要求后，直接复用当前生成状态。学习算子把它转换成与新条件相容的状态，再用原生生成器继续生成。

两个时间具有不同含义：

- `t`：原生生成时间，0 是噪声，1 是图像。
- `s`：状态编辑进度，0 是输入状态，1 是转换后的状态。

在 `s: 0→1` 期间，原生生成时间 `t` 不变。这是两种计算操作的分离，不表示两个向量场几何正交，也不表示编辑过程严格保留噪声协方差。

首版任务为**单轮生成中途编辑**，默认直接在 `t=0.36` 读取并编辑，不先回退到 0.07。训练覆盖 0.15、0.25、0.36、0.50，为不同干预时刻提供支持。闭环文生图自纠偏是主要部署场景；显式用户编辑共用同一算子。首版不承担多轮策略学习、干净图像一步编辑或任意时间泛化。

核心假设是：**学到相容的状态转换后，可以复用已经完成的生成工作，而不继续继承错误内容。** 不能把“中间态比纯噪声一定更好”当作前提。

## 2. 对原提案的裁定

### 2.1 保留的方向

1. 分开生成推进和固定时间上的状态编辑。
2. 利用 UND 的原生图像—指令表征指导 GEN 的状态转换，不另建跨注意力网络。
3. 主训练采用单步条件流匹配，不再对数十步原生尾段反传。
4. 用高质量编辑对定义正确变化，不蒸馏免训练纠偏搜索赢家。
5. 学完状态转换后交给冻结 T2I；原生 T2I 和原生 IT2I 都保持可独立使用。

### 2.2 必须修正的推论

| 原提案判断 | 裁定与实现后果 |
|---|---|
| 多步确定性流必然消除单步回归的多解模糊 | 不成立。固定输入、条件和确定性求解器仍只有一个输出。首版明确学习一个编辑选择，不宣称同一状态上的多模态采样。 |
| 配对直线意味着 2–4 步精确积分 | 不成立。每对样本的路径可以是直线，学习到的条件平均速度场通常不是常量。首版用 8 步 Euler，4 步作为训练后的成本档位。 |
| 部分 ODE 反演自动等于真实历史分布 | 不成立。任意图像可位于某条积分曲线上，但反演所得起点不一定来自原生高斯先验；反馈、预览和父条件的联合分布也会不同。保留真实父轨迹训练来源。 |
| 两幅图在 0.95 注入同一噪声，反演后噪声仍精确抵消 | 不成立。不同状态、条件和非线性动力学会改变耦合。共享噪声精确抵消只适用于规定的线性加噪构造。 |
| 反演至 0.95，再正向到 1，天然复原原目标 | 不成立。逆向后正向首先返回的是 0.95 的起始状态，剩余 0.95→1 仍会改变图像；离散求解还有往返误差。首版从 1 反演并记录实际重建误差。 |
| 源图 KV 必然把图吸回错误内容 | 不成立。原生编辑本身依赖源图条件。改用 T2I 是为了明确接续条件和减少视觉条件计算，不是证明 IT2I 必然锁死。 |
| 冻结 T2I 保证原生画质 | 不成立。异常输入状态仍可生成畸形图。冻结保护参数，状态相容性决定接续结果。 |
| THW RoPE 保证对应位置被精确读取 | 不成立。位置编码提供空间关系信息，不保证注意力定位或语义保持。 |
| 8000 条编辑数据足以代表通用结构编辑 | 不能由数量推出。现有 A 集可用于启动，但须按实际指令和变化记录覆盖；文字编辑不能替代计数、增删、移动的监督。 |
| 手工失败轨迹库没有价值 | 过强。它可以做针对性适配；本方案不把它作为主要数据组织方式，也不把数据生产本身作为创新。 |

E1 支持“原生编辑器从当前历史态接续存在适配缺口”，不支持“所有中后段状态都能被 T2I 忠实渲染”或“后训练必然破坏先验”。

## 3. 数学定义：目标相容状态，而非噪声等级不变的流形

### 3.1 条件与状态

定义：

- `c_parent`：产生输入状态、计算预览时使用的完整父条件。
- `c_tail`：转换后原生 T2I 使用的完整目标条件。
- `e`：本轮短编辑指令。
- `a`：时间 `t` 的输入状态。
- `b`：时间 `t`、在 `c_tail` 下能接续到目标的配对状态。
- `P`：从 `a` 的副本在 `c_parent` 下调用统一前瞻函数得到的预览。
- `σ`：底座原生噪声尺度，从模型配置读取，不硬编码。

自纠偏时 `c_parent=c_tail=c_raw`。错误来自一次生成没有满足提示词，不能把 `c_parent` 改成实际错图的描述后声称完全对齐自纠偏。

交互式改图时，`c_tail` 由 `c_parent` 和用户编辑指令更新。它是完整目标场景描述，不是“把它移到左边”这类孤立命令。

### 3.2 理想相容性

记 `Φ^c_{v←u}` 为条件 `c` 下、从时间 `u` 到 `v` 的原生流。理想编辑算子应满足：

\[
\Phi^{c_{tail}}_{1\leftarrow t}(T_t(a))
=E_e\big(\Phi^{c_{parent}}_{1\leftarrow t}(a)\big).
\]

`E_e` 表示指定的一种正确图像编辑选择；若任务有多个合理结果，应理解为选定耦合或结果分布，而不是唯一真实图像。

连续流存在且可逆时，可以定义：

\[
T_t=\Phi^{c_{tail}}_{t\leftarrow1}\circ E_e\circ
\Phi^{c_{parent}}_{1\leftarrow t}.
\]

这说明一种相容转换如何定义，不给出低成本实现、最小编辑性或先验分布保证。学习任务是近似该转换，而不是在部署时完整执行这三个昂贵操作。

### 3.3 编辑路径与主损失

使用配对状态构造：

\[
q_s=(1-s)a+sb,\qquad u^*=b-a,\qquad s\sim U(0,1).
\]

训练状态编辑场 `uθ(q_s,t,s;P,e,c_tail,b0)`；`b0` 是第 5 节定义的固定参考预测。主损失为：

\[
L_{\rm state}=\mathbb E\left[
\operatorname{mean}_{valid}\left|
\frac{u_\theta(q_s,t,s)- (b-a)}{t}
\right|^2\right].
\]

首版 `t≥0.15`，无需用任意极小数替代 `t`。除以 `t` 是时间权重选择，使线性数据上的目标成为 `x_target−x_source`，避免较晚时间天然占更大损失；ODE 数据仍使用真实 `(b−a)/t`，不假定它等于像素差。

该目标属于条件流匹配，标签来自固定概率路径的速度，不是终图展开损失。[Flow Matching](https://arxiv.org/abs/2210.02747) 已建立这种训练框架，本项目的贡献不能写成“首次用 MSE 学编辑流”。

### 3.4 多解问题的实际处理

MSE 的最优场仍是给定可见状态和条件后的目标速度条件均值。回归条件平均速度不等于最后一定生成条件平均图，标准流匹配可以输运多模态分布；输入态中的随机性也可以支持不同编辑选择。问题在于：原提案没有证明其锚定条件和短程积分能实现所需输运。因此，不能断言单步必糊，也不能断言多步必然消除模糊。

首版采用**确定性编辑选择**：固定父状态、指令和模型只返回一个结果，不增加随机刷新，不生成多候选后筛选。训练使用同场景、变化明确的配对；同源多条指令保留，但不能把相同输入对应的互斥布局强行当作唯一标签。指令没有规定的新物体位置，不从目标图偷取坐标作为部署不可得条件。

不同原生种子仍带来不同编辑结果。这不是“固定状态上的多模态生成”。若后续任务要求后者，应明确引入随机条件或随机桥；本版不把多跑几步伪装成随机模型。

### 3.5 状态保持不等于像素掩码外速度为零

在线性共享噪声配对中，未编辑像素相同确实给出零状态差。ODE 反演不具有这项逐像素性质：注意力、全局条件及反演动力学可能让保留区的状态也发生变化，随后在接续中恢复相同背景。因此，ODE 数据必须监督完整 `b−a`，不能强行将图像编辑掩码外的状态速度清零。保持度在最终图像上定义。

首版只在四个内部时间点训练。`t=0` 的乘零形式和 `t=1` 的图像差表达式都不构成端点能力证明；尤其 ODE 反演配对没有保证两端对应同一个初始噪声。本文不宣称统一了从噪声生成、中途编辑和干净图编辑三种模式。

### 3.6 质量误差怎样传到终图

对于某条配对记录，设接续在邻域内的 Lipschitz 常数为 `L_tail`，目标状态的实际往返误差为 `ε_inv`：

\[
\|\Phi^{c_{tail}}_{1\leftarrow t}(\widehat b)-x_{target}\|
\le L_{tail}\|\widehat b-b\|+\epsilon_{inv}.
\]

其中 `b̂` 是学习场实际积分后的状态。状态误差包含模型误差和编辑积分误差。这个局部界解释三件事：反演标签要有效、预测状态要接近标签、短程求解器不能随意减步。它不把像素范数界等同于感知质量保证。

## 4. 数据：现成编辑对开训，反演和真实父轨迹负责不同问题

所有图像先用同一成对变换进入 512×512 画布。源图和目标图禁止独立裁剪。保留有效区掩码，padding 沿用底座约定。同源家族只属于一个 split。

### 4.1 公共条件生产

每条编辑对保存 `(x_source,e,x_target,c_parent,c_tail)`。

- 原数据的短编辑指令作为 `e`，不换成教师长制图提示。
- `c_tail` 从源场景描述和 `e` 构造，表达所要求的变化。目标图只用于核对执行是否正确，不能把其中未要求的新布局写入学生条件。
- `c_parent` 与状态来源绑定，不得在缓存生产后修改。
- 可用 UND 或 GLM 补齐文本；冻结一个版本的条件协议。实体、属性、关系必须绑定，不能使用仅按词过滤的旧拆题逻辑。
- 同一组 `P,e,c_tail` 生成一个固定 UND joint cache。没有 `x_target`、目标 latent、目标特征或反演终点进入学生条件。

原生完整提示词不再像旧接续器那样一律从编辑条件中删除：本版需要显式知道后续 T2I 条件。输入模板分字段保存，避免把完整目标与本轮动作混成一句指令：

```text
Edit request: {e}
Generation target after editing: {c_tail}
Preserve: {confirmed_preserve_attributes}
```

保留项为空时省略该行。数量或位置错误时，不加入会锁住错误构图的存在性保持句。自纠偏首版修复完整目标的已确认失败项，不宣称在与 `c_tail` 冲突时还能只改其中一项。

### 4.2 L 数据：线性耦合编辑对，立即用于训练

对一条现成编辑对和同一噪声 `ε~N(0,I)`：

\[
a=t x_{source}+(1-t)\sigma\epsilon,
\quad b=t x_{target}+(1-t)\sigma\epsilon.
\]

因此 `b−a=t(x_target−x_source)` 精确成立。它提供空间变化监督，但这类 `a` 标为 `linear_pair`，不叫真实历史态。

`P=preview_image(a,t,grid,NativeT2I(c_parent))`，与部署使用同一前瞻代码。不能直接拿清晰源图或高斯模糊图替代 `P`。当前前瞻含三个速度求值，CFG=4 时通常是六个原生分支前向，因此预训练并非“零额外计算”。可缓存固定的 `(uid,t,noise_seed,P)`；更换噪声后必须重算预览。

首版时间采样：`{0.15:0.20, 0.25:0.25, 0.36:0.35, 0.50:0.20}`。这是显式的四时间点协议，不声称覆盖整个连续区间。

现有 8000 条 A 数据可作为首批输入。它们的短指令可以继续使用；按实际类别统计覆盖。如果以文字替换为主，训练日志应如实标记，不把文字编辑损失下降解释成结构编辑能力。已有其他结构编辑对可直接并入，不要求先造指定数量的计数失败样本。

### 4.3 I 数据：部分 ODE 反演配对，校准接续目标

对通用编辑对，计算：

\[
a=\Psi^{c_{parent}}_{t\leftarrow1}(x_{source}),
\qquad b=\Psi^{c_{tail}}_{t\leftarrow1}(x_{target}).
\]

`Ψ` 是具体数值逆向积分器，不用 `Φ^{-1}` 的符号掩盖离散误差。

默认实现：

1. 使用冻结原生 T2I、CFG=4、相同归一化与 `t_eps=0.05`。
2. 从 `t=1` 开始，用逆向 Heun 沿部署网格反向积分；首版每个原生区间再分成两个逆向小区间。模型端点求值沿用明确的 `t_eps` 截断，不替换成 0.95 加噪协议。
3. 一次反演记录四个训练时间点，反演和缓存为 `no_grad`；状态以 FP32 累积并保存。
4. 对每个拟使用的目标态，用部署的原生 Euler、实际 `c_tail` 正向接续。保存相对原目标的有效区 L1、LPIPS 和重建图。
5. 同样记录源侧重建误差，并从 `a` 生成 `P`。目标侧重建不合格的时间点不提供 IFM 标签，不把重建图改名为原来的真值。

初始缓存筛选值：有效区 L1 在 `[-1,1]` 坐标不高于 0.08，LPIPS-VGG 不高于 0.20。它们仅排除明显的重建失败，不代表语义和形体已合格；记录各类别、各时间点接受率。已有目标质量标签继续有效，自动距离不能替代目标本身的语义正确性。

这是训练标签生产中的常规验证，随训练并行执行，不是先做一组 Oracle 再决定是否允许训练。若某类反演持续不能保留目标，不反复搜索更多噪声，也不放宽阈值后声称该类已有相容监督；该类继续使用 L 数据，并在数据统计中显示缺口。

部分反演负责获得可接续的目标态。它没有证明源侧状态与部署同分布。不同条件的反演也不保留简单的公共高斯分量，不能用 `t(x_target−x_source)` 替代 ODE 标签。

### 4.4 R 数据：通用真实父轨迹，覆盖实际部署输入

为避免把反演输入当作真实历史，Stage 2 混入一类自动生产的真实父轨迹记录：

1. 从独立训练提示词池取提示词和一个固定种子，运行一次原生 T2I，记录四个节点及预览。
2. 使用部署诊断协议产生 `e`。正确样本留作保持记录；有错样本只生成一次高质量编辑目标。
3. 单次目标以同种子原生终图为源。可复用现有强编辑器接口或离线批处理；没有已确认可运行的目标生产接口时，R 数据明确为空，不伪造其完成状态。
4. 目标与指令一致且通过现有质量审核后，按第 4.3 节的方法在**原始完整目标条件 `c_raw`** 下反演目标，得到 `b`。
5. 源态 `a` 必须读取前向生成缓存；不得用源图反演值替代。`P` 由该节点调用同一前瞻函数得到，不从另一时间节点借用。

这类记录不按“250 个计数错误、150 个位置错误”手工配额，也不搜索成功种子或教师赢家。它是固定算法下的输入分布采样。生成目标仍需质量控制；拒绝不合格目标不等于进行 best-of-N 搜索。

R 的目的只解决一个具体缺口：部署源态来自高斯初始化后的真实前向过程，而任意图像反演态没有这种保证。首版目标为累计 2000–5000 条合格记录，作为 Stage 2 的一部分；它不是 Stage 1 开训条件。

若 R 暂缺，照常运行 Stage 1 和 I 配对训练，但检查点标记 `input_domains=[linear,inverted]`。只有真实父轨迹被实际训练后才加入 `native_history`，不能将完全相同的代码路径写成输入分布已经一致。

### 4.5 保持样本和划分

保持样本占训练记录约 10%。构造 `a=b`，使用明确的保持请求；同一条件、同一状态不能因为缓存分别重算而引入伪标签差异。

部署没有编辑要求时直接直通，不运行状态算子。保持样本约束的是显式“保持”请求和模型在无变化任务上的行为，不能把错误编辑指令配上零变化标签。

现有 E1、struct64 和 anchor search 的评测样本不进入训练。已有 A 的源图家族 split 保留，不把验证集重新命名为训练集来扩大数量。

## 5. 模型：原生空间表征 + 编辑进度条件 + 有明确单位的输出

### 5.1 保留与训练的参数

冻结：原生 UND、图像编码器、原生 GEN 权重、原生图像输出头、原生 T2I 和 IT2I 路径。

训练：GEN 全部层现有 rank-64 LoRA，以及 `edit_s_embedder`。仍使用现有七类线性层适配，不增加新跨注意力、误差定位头或特殊纹理层。

`edit_s_embedder` 采用与原生时间嵌入兼容的输出维度，其末层零初始化。将它加到原有 `t` 条件上。新增参数有明确职责：区分在相同生成时间上的不同编辑进度。

### 5.2 两个 UND cache 不是一次前向

每次编辑准备：

- `image_prefix`：仅预览图，供冻结参考预测。
- `joint_prefix`：预览图、`e`、`c_tail`、必要保留项，供适配场。

现有 `NativeEditor.prefixes` 分别 prefill 两个模板，实际是两次 UND prefill。可以共用图像编码结果，但不能在账本中写成一次完整 prefill。缓存仅在本轮编辑内部复用；图像、指令或目标条件变化后重建。

保留原生 THW 索引、视觉预处理和逐层 KV。UND 读的是 `P`，不把带噪 `a` 当作干净图送入原生 UND。

### 5.3 锚定输出参数化

使用原生输出头形状，但在本模式中把其输出作为可学习的图像坐标表示。先算固定参考：

\[
b_0=\operatorname{sg}[H_0(a,t;P)],
\]

其中 `H0` 是关闭 LoRA 的原生仅图分支的 clean prediction。定义：

\[
u_\theta(q,t,s;P,e,c_{tail},b_0)
=t\,[H_\theta(q,t,s;P,e,c_{tail})-b_0].
\]

- `b0` 每次编辑只计算一次，在 IFM 单步训练时也必须由原始锚点 `a` 计算，不能由插值状态 `q_s` 计算。
- `b0` 固定且不反传，`Hθ` 通过 LoRA 和 `s` 嵌入训练。
- `uθ` 的单位是“每单位编辑进度的状态变化”。**不能再除以 `1−t`，也不能调用旧 `edit_cfg`。**
- 状态编辑场首版不加 CFG，不训练条件 dropout。原生前缀、预览、反演和尾段仍使用 T2I CFG=4。
- 不裁剪 `q_s`、`Hθ` 或 `uθ`；仅给 UND/展示图片使用固定的输出变换。

在线性配对上，该参数化的理想头输出为 `b0+x_target−x_source`，未必是一幅真实干净图。在 ODE 配对上为 `b0+(b−a)/t`。因此不能继续把这个模式的输出称为“准确预测目标 clean image”。原生输出头提供初始化和坐标接口，不提供等时速度的正确性证明。

这是一种锚定的状态位移参数化，不是 FlowEdit 的精确源场抵消公式。FlowEdit 的差分依赖其自己的变量和耦合状态定义。[FlowEdit](https://arxiv.org/abs/2412.08629)

### 5.4 初始化与梯度

LoRA 保持一侧随机、一侧零。不要同时将 LoRA 两侧置零，也不添加一个零门控再乘零输出。

- LoRA 为零、`s` 嵌入为零时，`Hθ` 等于相应条件下的原生分支。
- 非空编辑条件下，`Hθ−b0` 通常不为零。初始化不是一个已验证的编辑算子，也不是全条件恒等映射。
- 若两个分支使用完全相同的条件模板，在 `q=a` 处可以得到零差分；这不能外推成训练后所有保持请求都精确恒等。
- 部署的精确无编辑保持由直通分支实现。显式保持请求由 `a=b` 样本监督。

原生 T2I/IT2I 的不变性来自独立的未适配视图。不能通过运行时全局 LoRA 开关改变另一个正在执行的分支；沿用当前模块视图方式隔离参数。

## 6. 直接训练配方

### 6.1 首轮共同设置

| 项目 | 首版决定 |
|---|---|
| 分辨率 | 512×512，共同成对变换与有效区 |
| 原生采样 | 50 步基础网格，shift=3，Euler，CFG=4，`t_eps=0.05` |
| 部署干预点 | 0.36，直接编辑该状态，不回退 |
| 训练时间 | 0.15、0.25、0.36、0.50，采样概率见第 4.2 节 |
| 编辑积分 | 8 步 Euler，均匀 `s` 网格，`t` 固定 |
| 训练 `s` | `U(0,1)`，每条样本随机一个值 |
| 可训练参数 | GEN rank-64 LoRA + `edit_s_embedder` |
| 主损失 | 有效区归一化 `L_state`；存在 padding 时沿用单独归一化 |
| 训练精度 | 冻结及适配前向 BF16；状态、插值、差分、损失和积分 FP32 |
| 优化器 | AdamW，betas=(0.9,0.95)，eps=1e-8，weight_decay=0 |
| 全局 batch | 64；64 卡时每卡 1 条，无额外梯度累计 |
| 激活重算 | 保留 GEN 层级 checkpointing，不做编辑/尾段全展开反传 |
| 梯度裁剪 | 1.0，记录裁剪前范数 |
| 保存 | 每 250 个更新及阶段末尾 |

不混入终图 L1、LPIPS 反传、`L_early`、repulsion loss 或长程代理梯度。LPIPS 用于缓存质量记录和成图评价，不进入本版优化目标。

### 6.2 Stage 1：现有编辑对上的状态编辑学习

数据：L 配对，含 10% 保持样本。按已有编辑类型均衡抽样，但不复制少量结构样本来伪造覆盖。

学习率 `5e-5`，前 100 步线性 warmup，随后余弦衰减到 `1e-5`。更新预算为：

\[
S_1=\min(6000,\lceil8N_L/64\rceil).
\]

`N_L` 是独立训练编辑对数，保持副本不另算新数据。8000 对时为 1000 个更新，10 万对时上限 6000 个更新。它限制小数据重复次数，不把“全量 DiT 要 20k 步”机械移植到本次适配器训练。

训练单步：

```python
source, target, e, c_parent, c_tail, valid = batch
optimizer.zero_grad(set_to_none=True)
with no_grad():
    t = sample_supported_time()
    eps = randn_like(source)
    a = t * source + (1 - t) * sigma * eps
    b = t * target + (1 - t) * sigma * eps
    P = native_preview(a, t, c_parent)
    image_kv, joint_kv = prefixes(P, e, c_tail)
    base_pred = frozen_image_clean(a, t, image_kv)
    s = uniform(0, 1)
    q = (1 - s) * a + s * b
    target_speed = b - a
pred_speed = state_velocity(q, t, s, joint_kv, base_pred)
loss = valid_mean(((pred_speed - target_speed) / t) ** 2, valid)
loss.backward()
optimizer.step()
```

`base_pred` 可缓存，但必须绑定底座、锚点和 image prefix。源/目标信息都可用于标签生产；学生 joint prefix 不能读取目标像素。

### 6.3 Stage 2：接续相容性适配

继续使用 Stage 1 权重，重置优化器动量；学习率 `1e-5`，warmup 100 步，衰减到 `2e-6`。

目标数据量：I 配对 1–2 万条，R 记录 2000–5000 条。缓存可以持续增长，不必等到全部生产完成才开始适配。一次缓存生产保存多个时间点，不视为多个独立源图家族。

有 R 数据时抽样比例为 L:I:R = 20:40:40；各来源合计保持样本占约 10%。R 未就绪时明确使用 L:I=20:80，并记录实际比例；不自动谎报 R 已参与。数据来源改变后日志保留变更步号。

预算：

\[
S_2=\min(4000,\lceil8N_{I\cup R}/64\rceil).
\]

训练依然只计算一个随机 `s` 的 IFM 损失。`P`、`a`、`b`、原生基准预测均可缓存。使用 Stage 1 完全相同的 `state_velocity`，不切换另一套状态定义。

### 6.4 工程开训顺序

1. 实现状态编辑模式、L 数据路径和新检查点格式。
2. 用现有合格编辑对启动 Stage 1。无需等待零训练对照或新图册。
3. 同时准备 I 缓存；R 的单次目标生产有可用接口后接入，不占用同一批训练卡做未经协调的后台采样。
4. Stage 1 预算完成后继续 Stage 2。I/R 到货情况决定日志中的实际输入域，不改变数学定义。
5. 成图观察随训练检查点进行，不成为训练前的批准流程。

本文给出的新命令和配置已按合同实现；开训前仍需检查本地数据和检查点身份。不能拿旧 `train` 入口加几项配置就当成本方案开训。

## 7. 推理协议和训推对齐

### 7.1 闭环文生图

1. 原生 T2I 使用 `c_raw` 从噪声积到 `r=0.36`，保存 `a`。
2. 从 `a` 副本前瞻，主状态保持不变。
3. UND/指定诊断器只核对原提示要求。无修改请求时沿原轨迹继续。
4. 有修改请求时固定 `c_tail=c_raw`，准备 `P,e,c_tail` 的 cache 和 `b0`。
5. 从 `q_0=a` 开始执行 8 步编辑 Euler：

\[
q_{m+1}=q_m+\frac1{8}u_\theta(q_m,r,m/8),\qquad m=0,\ldots,7.
\]

6. 得到 `b_hat=q_8` 后，丢弃本轮视觉条件缓存，用未适配的原生 T2I 在 `c_raw` 下继续 `r→1`。原生文本 cache 可以复用。

不刷新原始噪声，不在编辑内推进 `t`，不在转换后再额外叠加文本速度差。单次只返回一个结果。

### 7.2 显式用户编辑

条件更新为完整 `c_tail`；在 UND 的 joint prefix 和后续 T2I 中使用同一字符串。重新构建目标文本 cache，不能继续使用旧条件 cache。预览仍由旧父条件在当前状态副本上生成。

本模式需相应 I/R 训练记录覆盖，不能用仅自纠偏训练宣称任意交互编辑已验证。

### 7.3 一致性合同

| 对象 | 规则 |
|---|---|
| `t` 的含义 | 始终是原生生成时间，编辑内固定 |
| `s` 的含义 | 仅为状态编辑进度，不经过原生 timestep shift |
| 输入状态 | L/I/R 分开标记；R 使用真实前向缓存 |
| 预览 | 相同函数、相同父条件、同一个输入节点；不借用未来终图 |
| 编辑条件 | 相同模板；显式包含实际 `c_tail`；无目标像素泄漏 |
| 锚定基准 | 始终由输入 `a` 计算一次，而不是由当前 `q_s` 重算 |
| 输出单位 | 每单位 `s` 的状态位移，不是原生去噪速度 |
| 编辑场 | 训练、推理共用同一函数，不加未经训练的 CFG |
| 原生尾段 | 冻结 T2I、实际目标条件、同一网格与数值约定 |
| 多步误差 | FM 训练看配对路径；推理看学生路径，存在积分与分布误差，不能称逐状态完全一致 |

这里的一致性是计算合同，不是所有输入分布相同的承诺。Stage 1 的合成态和 Stage 2 的反演态是明确标记的训练分布；R 数据提供实际部署输入域。

## 9. 计算成本：先给可核算的调用数，不虚构倍速

原生 shift=3 时：

\[
t=\frac{u}{3-2u},\qquad u=\frac{3t}{1+2t}.
\]

`t=0.36` 对应 `u≈0.628`。原生 CFG 的一次速度通常包含两个 GEN 分支求值。忽略插入节点时，一次 50 步 T2I 约为 100 个短 KV 分支求值。

本版触发编辑的原始求值账本为：

\[
C_{GEN}=2N_{prefix}+6+(1+N_s)+2N_{tail}.
\]

括号内是一遍冻结 image baseline 加 `N_s` 遍 joint state field，均含视觉条件。`N_s=8` 时约为 115 个 GEN 分支求值，另加诊断、两份 UND prefill 和图像编码。实际插入节点会改变总数，程序记录为准。

与同一读取点后从纯噪声重启原生 IT2I 相比，复用部分前缀有明确的求值数优势；但 9 个长 KV 求值不能直接等同于 9 个短 KV 求值。未实测前不写“2 倍加速”“只增加 13% 延迟”或人为指定长 KV 折算系数。

无错路径没有状态转换和回退开销，仍有前瞻与诊断成本，不能称零额外开销。

训练成本也分开记录：

- L 数据在线一条：前瞻约 6 次冻结分支 + 1 次冻结 baseline + 1 次可训练分支及反向 + UND prefill。
- I/R 已缓存预览后：1 次 baseline + 1 次可训练分支及反向 + UND prefill；baseline 缓存命中时省去前者。
- 反演和往返重建是离线生产成本；一次反演可供多个时间点使用，但每个时间点的重建和预览仍有成本。

记录训练 NPU 秒、数据生产 NPU 秒、部署端到端秒和峰值显存。去掉长程反传会减少计算图深度，但不在实测前承诺训练快数十倍。

## 10. 随训练开展的成图评价

不做训练前 Gate 0。Stage 1 的常规检查点直接开始成图，Stage 2 沿用同一开发集。训练 loss 只判断优化状态，不代表画质已解决。

首轮固定 64 个开发案例，不把它们加入训练；检查点取 250、1000 和阶段末尾，重合时只出一次图。每次单种子、单输出，不做生成后选优。看三类结果：指令是否实现、原有正确内容是否改坏、畸形/融合/重影是否增加。已有 VLM 分数保留，人工形体判断与其分列。

形成论文结论时只安排承担明确问题的比较：

1. **主效果与成本**：原生终图 IT2I、同读取点纯噪声 IT2I、本方法；共用源轨迹、编辑请求和成图预算口径，报告完整前缀/预览/诊断成本。
2. **历史态是否真的有用**：相同条件下，直接从 `a` 走原生 T2I，与学到 `T(a)` 后接续比较。证明改变来自状态编辑而不是仅换提示词。
3. **数据相容性是否有用**：Stage 1、加入 I、加入 R 的实际检查点比较，不额外训练多条配置网格。
4. **UND 空间表征是否发挥作用**：唯一增加的一条匹配训练支线，用文本条件替代视觉条件；不能在推理时直接拿掉 KV 的分布外结果当作架构价值证明。
5. **成本前沿**：同一个训练模型用 4/8 步、支持的不同干预时间形成质量—延迟曲线；不预设 4 步更优。

样本量按主效应的不确定性决定；给成对置信区间、整图修复/破坏计数和人工畸形统计，不用一个固定样本量替代证据。FlowEdit 可在其支持的模型与输入任务上作为外部方法参照，不把跨底座差异直接归因于本算子。

## 11. 创新性、风险与可写结论

### 11.1 最接近的方法基础

- [Flow Matching](https://arxiv.org/abs/2210.02747)：给定路径的速度回归。本方案复用其训练思想。
- [FlowEdit](https://arxiv.org/abs/2412.08629)：构造源到目标的直接编辑 ODE。差分、编辑流和无需部署反演本身均不是新贡献。
- [I²SB](https://arxiv.org/abs/2302.05872)：以有信息的输入而非纯噪声为起点学习图像间桥接。不能宣称首次从有结构状态出发学习转换。
- [FlowAlign](https://arxiv.org/abs/2505.23145)：研究编辑轨迹控制和一致性。轨迹相容、保持结构这些目标本身已有研究。

UND 前瞻质检、GEN LoRA、源图 KV 和条件流匹配分别已有基础。论文贡献应放在它们共同实现的**生成中途状态编辑能力与成本收益**，不能把已有模块逐个列成创新。

### 11.2 值得建立的三项结果

1. 在原生生成时间不前进的情况下，完成语义状态转换，并由未适配 T2I 正常接续。
2. 高质量编辑对通过统一状态配对规则提供监督，接续适配不依赖 best-of-N 教师或手工失败类别配额。
3. UND 的空间语义表征支持状态相关的选择性变化，在实际质量—成本曲线上优于重画或完成后再编辑。

### 11.3 决定结果的风险

- **语义多解**：本版选一个确定结果，没有消除条件均值问题；若仍出现平均布局，应重新设计随机性/耦合，而不是声称多加两步已解决。
- **反演目标漂移**：不合格缓存会直接教坏状态转换；由往返记录定位，不用终图辅助损失补偿错误标签。
- **源分布差异**：I 数据不能替代 R；实际 history 成图检验其迁移，不把“满足同一 ODE”当作同分布证明。
- **接续放大误差**：冻结 T2I 不能修复所有坏状态；输出状态误差和成图形体同时看。
- **配对不保持场景**：视角重写或背景重画会使标签要求无关变化，必须从数据意义上处理，不能靠添加保持损失抵消。
- **短程求解误差**：8 步是预算，不是定理；4 步质量变化决定是否进入较快的部署档位。

本版撤回“等噪流形精确平移”“2–4 步精确完成”“反演后严格同分布”“100% 原生画质”和“已达到 FlowEdit 级创新”的表述。保留明确而可训练的主张：**将编辑目标前移到生成状态，学习可由原生生成器接续的转换，争取以更少重复生成完成语义修改。**

## 12. 实施交付点

这份方案不要求先通过一个零训练上限实验。接下来的实现应交付：

1. 固定 `t` 的状态流、单步 IFM 训练入口及完整检查点。
2. 可直接消费现有编辑对的 L 数据路径。
3. 可并行生产的 I/R 缓存路径，来源与质量记录不混淆。
4. 真正使用冻结 T2I 接续的推理入口，以及实际调用数/延迟日志。

在上述代码完成前，当前选择性历史编辑器的训练不能代表本方案。首轮训练从原生底座初始化的新适配参数开始，不加载旧残差或旧完整接续 LoRA。
