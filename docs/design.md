# Design

BAGEL-LatentCoT 通过一段连续 memory，让理解专家读取生成状态，并将目标偏差转化为生成反馈。

[README](../README.md) · [实验](experiment.md)

## 1. 目标：在生成过程中形成反馈

图像生成器根据目标文字预测当前噪声状态的演化速度。理解专家擅长从上下文提取语义、比较事实与目标。Memory 连接这两种能力：先获取当前生成信息，再形成生成器能够消费的修正条件。

反馈的目标是让下一遍生成朝目标方向修改，同时保留已有正确内容。系统同时学习信息获取、反馈转化和生成消费三种关系。

| 角色 | 提供的信息 | 承担的计算 |
|---|---|---|
| 目标 prompt | 期望的对象、属性、数量与关系 | 定义比较目标 |
| 生成专家 GEN | 当前状态的内部表征 | 预测图像演化速度 |
| 理解专家 UND | 文字与生成表征之间的语义关系 | 获取状态信息，形成修正 |
| Memory | 固定长度的连续反馈表示 | 将 UND 的判断传入 GEN |
| 外层采样器 | 当前状态与时间 | 用最终速度推进图像状态 |

## 2. 目标与生成状态分别进入理解专家

键值表示 KV 由注意力的 key 与 value 组成。记第 $l$ 层目标文字的 KV 为 $P_l$，当前 GEN query 的 KV 为 $G_l$，读取生成来源的层集合为 $\mathcal L$。反馈 writer 的来源为：

$$
S_l=
\begin{cases}
[P_l;G_l],&l\in\mathcal L,\\
P_l,&l\notin\mathcal L.
\end{cases}
$$

目标文字在全部 UND 层可见。来源窗口决定各层是否同时读取 GEN 状态。GEN 来源包含当前图像 query 与原生图像边界 token；目标文字缓存和上一遍 memory 各自保留独立身份。

这种分工为 UND 提供清楚的比较关系：P 表示目标，G 表示当前生成信息，memory 表示理解后形成的反馈。层窗口控制信息读取的位置，连续 UND 负责跨层转化。

## 3. 连续 memory 的写入与消费

Memory 使用 16 个槽位，由固定中性文本表示初始化。中性种子为 UND 与 GEN 提供共同的文字接口起点。每次反馈都从相同种子开始写入。

设 $H_l$ 为 memory hidden，$F_l$ 为第 $l$ 个 UND block，$A_l$ 为已有写入残差，则：

$$
U_l=F_l(H_l;S_l),\qquad H_{l+1}=U_l+A_l(U_l).
$$

Hidden 连续经过 UND 各层。时间条件 query 残差根据实际噪声时间调整读取。文本写入采用文字来源，视觉反馈写入采用目标与 GEN 来源。

每层更新后的 hidden 经同层 UND 归一化和 K/V 投影导出 memory。导出的 key 在消费时应用对应上下文的旋转位置编码 RoPE，来源 key 保持其原生位置编码。

GEN 的条件上下文由目标文字、memory 和当前 query 组成：

$$
K=[K_P;K_M;K_G],\qquad V=[V_P;V_M;V_G].
$$

目标文字继续承担全局内容约束，memory 提供状态相关的修正。Memory 获得自己的位置，图像 query 随附加条件后移。UND 的文字读出使用相同 memory，并采用自身读出上下文的位置。

## 4. 同一状态内的反馈循环

一次内层循环固定图像状态 $x_t$、时间 $t$ 和目标 $p$。记 $M^{(0)}$ 为空反馈：

$$
G^{(r)}=\operatorname{GEN}_{\mathcal L}(x_t,t,p;M^{(r-1)}),
\qquad M^{(r)}=W(P,G^{(r)},t).
$$

每遍 GEN 从该状态的原生入口重新计算。UND 读取本遍来源，重新写入 memory。下一遍 GEN 消费新 memory，得到新的来源与速度。

中间遍运行到所需来源层段，最终遍完成全部生成层与速度头。训练中的直接速度监督使用完整出口。外层采样器在内层反馈结束后消费最终速度，推进一次图像状态；下一外层节点重新开始反馈。

BAGEL 的流匹配约定为：

$$
x_t=(1-t)x_0+t\epsilon,\qquad v^*=\epsilon-x_0,
\qquad x_s=x_t-(t-s)v_{\mathrm{CFG}}.
$$

其中 $x_0$ 是干净图像 latent，$\epsilon$ 是噪声，较大的 $t$ 对应更高噪声。CFG 是无分类器引导；memory 进入条件分支，其他分支沿用相应原生条件。

## 5. 显式文字反馈与连续反馈

两条反馈路径共用目标文字、memory 容量和 GEN 消费接口。

| 路径 | 获取信息 | 形成反馈 | 写入 memory |
|---|---|---|---|
| 连续反馈 | 当前 GEN query KV | UND 根据目标与状态进行转化 | P 与 G |
| 显式反馈 | 完整预览图与目标文字 | BAGEL 图像理解产生文字修正 | P 与修正文字 C |

显式教师将反馈分为当前事实、目标差异和正向修正。修正文字通过原生 UND 在目标之后预填充，文本 writer 读取目标 KV 与新增修正段 KV。图像理解会话的表征留在反思路径，生成侧消费由文字重新构造的条件。

显式反馈先完成一次原生生成，再通过 BAGEL 图像理解形成文字修正。文本 writer 将修正写入一份固定 memory，第二次生成从完全相同的初始噪声开始，在选定时间窗口内持续消费该 memory，窗口结束后沿原生过程生成终图。

显式文字教师提供可检查的语义参照。连续 memory 的训练目标是从生成内部信息形成同样可执行、并能随状态更新的反馈。

## 6. UND 的两个学习任务

### Observe：获取生成信息

Observe 从 GEN 来源恢复图像描述，建立对对象、属性、数量和关系的读取能力。Writer 的直接输入为 GEN KV；生成来源保留其原有文字条件。

Observe 是辅助训练任务。部署时，Feedback writer 直接形成连续 memory，文字读出用于检查其中的信息。

### Feedback：形成目标相关的修正

Feedback 读取 P 与 G，输出针对当前状态的修正，或保持当前结果。描述当前图像与判断目标偏差共用 UND 和同一 memory 接口。

文字监督建立语义表达。生成监督建立“这种反馈应怎样改变下一遍速度”的关系。两者共同连接反馈内容与图像修改。

## 7. 噪声决定监督的信息范围

低噪声状态保留较多图像内容，适合从干净图描述建立恢复任务。噪声增加后，状态中的可辨识信息减少；对应任务通过噪声课程逐步扩展。

监督区分三种作用范围：干净端点、实际状态和生成预览。端点描述支持其有效噪声范围内的恢复；实际状态标签绑定具体状态；预览反馈描述沿当前出口继续生成后需要修正的内容。

高噪声学习主要使用正确目标的生成监督，以及绑定真实生成结果的反馈。纯噪声在相同目标与种子下具有相同输入，其学习目标来自目标图的条件生成分布。

## 8. 生成监督与保持

对编辑关系 A→B，目标 P 描述 B。A 提供修正反馈，B 提供保持反馈。配对 flow 的目标属于构造当前插值状态的干净图：

$$
v^*=\epsilon-x_0.
$$

A 端的纠错采用有效文字教师速度；B 端的生成采用 B 的配对 flow。保持教师使用相同的位置布局，并将新增 memory 区域屏蔽，使保持目标对应原生生成行为。

训练目标包含语义负对数似然 NLL、完整条件速度均方误差 MSE 和配对 flow MSE：

$$
L=m_o\lambda_oL_o+m_f\lambda_fL_f
 +m_T\lambda_T\|v_S-v_T\|^2
 +m_F\lambda_F\|v_S-(\epsilon-x_0)\|^2.
$$

$m$ 表示当前任务、噪声与标签范围对应的监督资格。教师和学生共享当前状态、目标及原生条件；速度比较使用 CFG 前的条件出口。

主线冻结原生 UND、GEN、VAE、embedding 和速度头，训练已有 writer 与视觉 query 残差。生成损失经过冻结 GEN，将输入梯度传回 memory。文本教师保持独立冻结。

多轮训练逐遍更新来源和反馈标签。目标图配对 flow 可监督各遍出口；状态相关的文字与教师速度对应各遍自己的结果。

## 9. 原生条件图与后续生成适配

条件图通过 BAGEL 自带的变分自编码器 VAE 预填充进入 GEN。目标噪声从目标图构造。Writer 继续读取独立的目标文字与当前 GEN query，维持统一的反馈接口。

训练先建立生成信息的读取，再建立单次反馈和多轮修正。后续生成侧适配以可靠 memory 为条件，更新原生 GEN 的消费能力；终图监督进一步约束修改正确性、正确内容保持和视觉质量。
