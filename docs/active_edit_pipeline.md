# 主动编辑数据管线（当前配置）

更新：2026-11-10 14:15。取代 [数据构建第二版](isochronic_data_plan_v2.md) 中的生产实现部分，
方案本身不变。

## 1. 三个作业

| 作业 | 跑在哪 | 内容 |
|---|---|---|
| 指令生成 | CPU（Metto API） | GLM-5.3-flash **看图**，输出指令 + bounding box；8 进程 × 24 线程 |
| 轨迹渲染 | modelarts-64 | 64 卡，`x_src` + t∈{0.25,0.36,0.50} 三时刻的 `a_t` / `P_t` |
| 轨迹渲染 | modelarts-64b | 64 卡，分片错开（`--shard-index 1 --shard-count 2`）避免重复 |
| 验收 | CPU | `verify_by_pixels.py`，**不调用任何模型** |

## 2. 为什么去掉 8B 依赖

看图版候选的 8B 验证里 `subject_absent` 占 18.3%，但样例显示：

```
"Remove the rightmost brass telescope and its tripod."
```

对象明明在图里。**是 8B 判分器无法指认"最右边那台黄铜望远镜"**，把对的判成了错的。
现在由 GLM 给出边界框，对象是否存在由坐标证明，像素比对给出编辑与保留的证据。

## 3. 一条记录的来源关系

```text
同一父轨迹（同一 uid，同一 seed）
  ├─ a_0.25, a_0.36, a_0.50            各自的真实状态
  ├─ P_t                                各自的预览（不共用）
  ├─ x_src                              原生完稿
  ├─ e, c_tail, EDIT_BOX, PRESERVE 框   GLM 读 x_src 产出
  └─ x_eff                              教师执行 e 后的成图
```

## 4. 验收（纯像素）

| 检查 | 判据 | 参数 |
|---|---|---|
| 编辑发生 | `EDIT_BOX` 区域在 `x_src → x_eff` 的均值绝对差 | > 0.06 |
| 保留守住 | 每条 `PRESERVE` 框的差 | ≤ 0.04 |
| 框有效 | 缺框直接拒绝（`no_edit_box`） | — |

两个阈值在首批上校准，属于实验参数，会随数据改写进本节。

## 5. 已知限制

- GLM 给的框可能过大或过小，像素判据会因此偏宽或偏严；首批之后要重新校准阈值。
- `c_tail` 由 GLM 给出，可能与原提示词有风格差异；训练时它决定尾段条件。
- 多时刻共享同一个 `x_eff`，但每个时刻各自展开自己的尾段（尾段长度不同）。

## 6. 当前进度目标

20,000 条轨迹（每条三时刻 + `x_src`），之后转完整训练样本生产。
