# Hard64 六组 memory 对照：仅指标审计

## 结论

这次运行证明了 memory 干预对同状态速度场有可测影响，但不证明图像质量或语义正确率提高。
相对于零初始化动态 memory，引入 Read memory 的变化最大；正确与交换 memory 的差异、
以及正常演化与冻结 memory 的差异较小但非零。因此证据支持“Read 状态影响模型行为”，
尚不足以支持“主要收益来自正确 prompt 内容”或“动态 memory 演化提高质量”。

没有读取或查看图片；pixel MAE 直接读取既有 manifest，没有重新解码图像。
没有重跑推理、修改远端代码、上传报告或干预进程。

## 指标定义与汇总口径

同状态探测：每个 timestep，六组都接收相同的 native x_t；只由 native 推进探测轨迹。
独立最终生图另行运行，不能将最终图像距离与同状态速度距离混成一个指标。

对比速度指标为 `||v_left-v_right||_2 / (||v_native||_2 + 1e-12)`。
v 是最终 CFG 后的速度。下表百分比是该范数比，不是准确率、收益占比或解释方差。
先对每条 prompt 的 49 步等权平均，再对 64 条 prompt 等权平均；表中 P10/P90
是 64 个 prompt 均值的分位数，不是置信区间，3,136 个时间点也不是独立样本。
各组差异向量及其范数不能当成可相加的贡献分解。

| 对比 | 等步权重均值 | prompt 中位数 | P10–P90 | 绝对速度差范数均值 |
| --- | ---: | ---: | ---: | ---: |
| static-null − native：保留零 memory 位置 | 2.349% | 2.339% | 2.181–2.546% | 9.191 |
| zero-dynamic − static-null：允许零起点演化 | 6.684% | 6.650% | 5.510–7.950% | 25.673 |
| normal − zero-dynamic：引入 Read 状态 | 12.829% | 12.882% | 10.993–14.779% | 49.750 |
| normal − shuffled：交换 Read 状态 | 3.514% | 3.397% | 2.650–4.773% | 13.746 |
| normal − frozen：允许 Write/suffix 演化 | 3.371% | 3.381% | 3.007–3.713% | 13.231 |

所有 64 条 prompt 上，normal−zero-dynamic 的逐步平均差异均大于其余三项
dynamic、specificity、joint。specificity 与 joint 的全局均值分别约为 content 的
27.4% 和 26.3%；这是距离之比，不能解释成“27.4% 的效果来自语义内容”。

native 速度范数范围 287.815–510.868，均值 392.549；相对指标没有接近零分母的问题。

## 六组相对于 native 的变化

hidden 指标只来自条件分支；body 在 layer 19 后取样，suffix 在最终归一化后取样。
pixel MAE 使用 0–255 RGB 尺度，是 manifest 已保存的独立最终图像差异。

| 模式 | 速度相对差异 | body hidden 相对差异 | suffix hidden 相对差异 | pixel MAE 均值 | pixel MAE 中位数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| native | 0% | 0% | 0% | 0 | 0 |
| static-null | 2.349% | 0.574% | 0.559% | 3.528 | 2.543 |
| zero-dynamic | 6.731% | 2.517% | 1.273% | 21.329 | 20.131 |
| normal | 12.449% | 5.161% | 2.644% | 30.287 | 28.231 |
| shuffled | 12.448% | 5.156% | 2.650% | 30.431 | 28.447 |
| frozen | 13.131% | 5.412% | 2.980% | 30.339 | 28.042 |

normal、shuffled、frozen 与 native 的距离接近，但不等于三者输出相同。
必须同时看直接配对差异（3.514%、3.371%），不能仅凭“到 native 的距离相似”
断言忽略 memory 内容或动态更新无效。

`cos(v_normal-v_native, v_zero_dynamic-v_native)` 均值 0.239；
prompt 均值 P10–P90 为 0.207–0.278。normal 的扰动并非简单放大 zero-dynamic 的同一方向。

## 时间位置与权重敏感性

| 去噪阶段 | 每条 prompt 时间步数 | normal−zero-dynamic | normal−shuffled | normal−frozen |
| --- | ---: | ---: | ---: | ---: |
| 早期 t>0.8 | 22 | 20.390% | 2.980% | 2.548% |
| 中期 0.4<t≤0.8 | 19 | 8.380% | 4.928% | 4.892% |
| 后期 t≤0.4 | 8 | 2.600% | 1.622% | 2.024% |

Read 状态与零状态的区别在高噪声早期最强，交换内容与冻结更新的差异在中期最大。
但 CFG 在 t≤0.4 关闭，因此晚期变化同时受到 guidance 切换影响，不是纯时间因果效应。

时间点由 shift=3 产生，等步平均会给早期较多权重。作为敏感性检查，使用相邻 t 的
差值 Δt 加权后，五个对比依次为 **2.117%、4.778%、8.505%、3.340%、3.342%**。
最大的对比仍是 normal−zero-dynamic，但其相对优势缩小。Δt 加权距离也不是最终
图像差异的严格分解，因为向量方向与独立轨迹都会变化。

## 注意力诊断

以下只涵盖 body layer 12、19；每层对全部 query/head 精确平均，再对 prompt/时间平均。
不是全网络注意力，也不能单凭 attention mass 得出语义因果结论。

| 模式 | Write GEN→memory，L12 | Write GEN→memory，L19 |
| --- | ---: | ---: |
| static-null | 0.032% | 0.127% |
| zero-dynamic | 1.821% | 0.288% |
| normal | 17.652% | 10.990% |
| shuffled | 17.632% | 10.978% |
| frozen | 17.652% | 11.448% |

normal 的 GEN→prompt 注意力，L12 从 native 的 13.490% 降至 10.200%，
L19 从 6.291% 降至 4.280%。prompt KV 没有被 mask；这是注意力分配变化。

normal Read 阶段 memory→prompt：L12 28.962%、L19 20.379%；
memory→GEN：L12 14.759%、L19 20.160%。因此 Read memory 确实接触 prompt 与当前
图像状态，但读取注意力不等价于保存或正确使用了任务语义。

## 实现控制核查

共核查 68,992 条 attention 记录和 9,408 条 memory-check 记录：

- static-null 所有已记录层的 memory hidden 最大绝对值均为 0。
- Read 的 GEN→memory mass 全部为 0；符合 strict Read 控制。
- zero-dynamic 的 Write 入口范数均为 0。
- normal 的 Write 入口范数等于自身 Read 范数；shuffled 的入口范数逐样本逐步等于
  配对 donor 的 Read 范数，未发现错误配对。
- frozen 的 Write/suffix hidden 最大绝对值逐层保持一致；全部 trace 数值有限。

这些是记录层面的必要条件，不是对全部张量的事后逐元素证明。运行产物没有保存完整
Q/K/V，不能单靠本次日志复核逐元素严格零 QKV；该性质由匹配源码与先前单元测试支撑。
同理，frozen 的最大值一致不能单独证明整个 hidden 张量恒等。

## 解释边界与下一步

1. “有 Read 状态”与“有正确 prompt 语义”不同。normal−zero-dynamic 同时改变
   hidden 的尺度、方向、分布，不能将 12.829% 全部解释为有用语义内容。
2. shuffled 交换的是不同 prompt、不同图像噪声状态对应的完整 memory；该差异反映
   样本特异性，不能单独隔离纯 prompt 语义。原 prompt KV 在所有组中仍然可见。
3. frozen 在 Write 与 suffix 都冻结；normal−frozen 是这整个区间的联合效应，
   不是单独 Write 更新的贡献。
4. 当前没有 GenEval/TIFA/VQA 正确率或人评；不能说 normal 优于 native，也不能
   因 normal/shuffled 的 MAE 接近就认定二者语义质量相同。
5. 后续若要验证正确 memory 的实际收益，应对现有六组图片计算同一套语义分数，
   优先比较 normal 与 zero-dynamic / shuffled / frozen；不必先重跑这批推理。
   这是建议，尚未执行或获准启动评分服务。

路由建议：现有数据可复用于后续 analysis-campaign；不要重复生成已完成图像。
主要待补证据是统一语义评测与跨 seed 稳健性，而非再确认本次文件是否齐全。
