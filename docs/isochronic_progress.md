## 1. 目前的结论

模型已经能在编辑对上执行加主体、改文字、改位置等变化，部分结果可以清晰地继续生成。真实文生图轨迹上的反馈编辑仍然容易产生碎纹、硬边和形体变形。

下一轮保留现有模型，重点改**监督的位置**：粗糙度跟着"条件切换"走——`b` 与尾段同条件时高频比 0.95，换一次条件 1.70–1.85，再求逆 3.12（§3.3）。也就是说标签本身仍有约 1.8 倍画质代价，而 `b-a` 状态 L2 损失看不见尾段的吸引域，没有理由避开这条路。

当前决定：

- 使用已有高质量编辑对作为 L 数据，保留已学到的编辑能力。
- 继续生产真实父轨迹和显式编辑目标，建立 R-edit 与 R-keep。
- I 数据暂不进入下一轮主训练，暂缓大规模重产。
- 默认使用稳定的逆向 Heun；离散不动点反演只保留为实验项。旧反演标签的粗糙度（3.12）已经被量出，耦合前向路线不再需要它。
- 学生一步恢复桥继续保留，作为训练技巧，不列为主要创新。
- 画质从"人工待审"改成硬指标：训练与评测都报 `hf_eff/hf_src`，超过约 1.5 即不合格。

## 2. 先把几个名字说清楚

| 名字 | 通俗解释 | 当前用途 |
|---|---|---|
| `a` | 编辑开始时的带噪图像状态 | 学生的输入 |
| `b` | 编辑完成后、仍处在同一生成时刻的目标状态 | 学生的监督标签 |
| `P` | 从 `a` 的副本快速预测出的预览图 | 让理解专家看到当前场景 |
| `t` | 原生生成进度，0 是噪声，1 是图像 | 当前主要使用 0.36 |
| `s` | 编辑进度，0 到 1 | 固定 `t`，用 8 步完成编辑 |
| L | 源图和目标图混入同一份噪声构成的编辑对 | 编辑能力训练与回放 |
| I | 源图和目标图都反演到中间时刻形成的编辑对 | 本轮暂不使用 |
| R-edit | 输入 `a` 来自真实生成轨迹，输出 `b` 来自编辑目标的反演 | 真实入口上的编辑训练 |
| R-keep | 输入来自真实轨迹，目标直接设为同一个状态，即 `b=a` | 学习保持当前画面 |
| `x_edit` | 图像编辑器生成的候选目标图 | 提出一次编辑结果 |
| `x_eff` | 从标签 `b` 出发，用冻结原生尾段实际生成的图 | 标签最终能生成什么，以它验收 |

R 的定义取决于输入状态是否来自真实前向轨迹，不取决于目标图由哪个模型生成。把外部源图送给 SenseNova 编辑，不会自动变成 R 数据。

### 3.2 怎么理解已有结果

在线性验证集 32 例上：

| 检查点 | 位移 MSE，越低越接近配对标签 | 学生态接续 MSE，越低越接近目标图 |
|---|---:|---:|
| 旧 `step_003607` | 0.1064 | 0.1319 |
| `stage1b/1200` | 0.0966 | 0.1210 |
| `stage2/500` | 0.0758 | 0.0970 |
| `stage2/1000` | 0.0810 | 0.0982 |
| `stage2b/1000` | 0.0806 | 0.0962 |

`stage2/500` 的位移 MSE 最低；`stage2b/1000` 的接续 MSE 略低。两个指标没有选出同一个最优检查点。现有结果不足以用“500 步已经收敛”代替实际成图判断。

图册中的主要观察：

- **编辑对：** 新增凤凰、中文替换和空间变化已经发生；部分样例仍有新增主体不完整、身份或构图变化。
- **真实反馈编辑：** 长颈鹿、牛角包和卡车等样例出现明显碎纹、硬轮廓或重影；计数修改有时只是把原对象擦淡。
- **保持任务：** 16 例的 LPIPS 从 0.1574 降到 0.1427，L1 从 0.0700 升到 0.0733。两项一起保留，不能只取较好的一个来概括画质。

高频能量增加可能是细节，也可能是碎纹。位移 LPIPS 增加表示感知距离变大，不能当作编辑改善。

### 3.3 画质审计：粗糙来自条件切换，不来自尾段

图册只有 JPEG 内嵌图，所以用高频能量、编辑区外高频、16/32 px 网格能量三个量做相对比较：同一批里每张图都按同样方式编码，比值可比。脚本 `scripts/audit_xeff_quality.py`，可复跑、可做门禁（`--gate`，非零退出）。所有数字相对**同一轨迹的原生完稿图**，中位数：

| 对象 | 条件关系 | 高频比 | 编辑区外高频比 | 网格比 | 超过 1.5 |
|---|---|---:|---:|---:|---:|
| 旧检查点 `step_003607`（线性域） | — | 0.99 | 1.09 | 0.84 | 2 / 25 |
| `stage2/000500` 学生输出 | 学生 → 尾段 | **1.77** | 1.57 | 1.20 | **18 / 25** |
| 耦合 text 分支（`--teacher text`） | `b` 与尾段**同条件** | **0.95** | 1.04 | 0.98 | 4 / 48 |
| 耦合 it2i 分支试点（24 例） | 换一次条件 | 1.45 | 1.36 | 1.34 | 10 / 24 |
| 耦合 it2i 分支 v5 全量（224 例，通过 174） | 换一次条件 | **1.85** | 1.68 | 1.55 | 143 / 174 |
| ↑ 与 text 臂配对的同一 48 例 | 换一次条件 | 1.70 | — | 1.51 | 44 / 48 更糙 |
| 旧反演路线的候选 `x_edit` | 外部编辑 | 2.10 | 1.85 | 1.69 | 47 / 51 |
| 旧反演路线的标签 `x_eff` | 换条件 + 求逆 | **3.12** | 2.53 | 1.75 | 51 / 51 |

一条命令复现：`python scripts/audit_xeff_quality.py artifacts/isochronic_round2_20261108`（9 秒，逐专辑逐列；加 `--gate` 用退出码做门禁）。

读法与结论：

1. **粗糙度跟着"条件切换"走，不跟着尾段走。** 同一批 48 条请求、同一份源缓存、同一个尾段，只改 `b` 是怎么造出来的：`--teacher text`（`b` 与尾段同条件）高频 0.95、网格 0.98、48 例里只有 4 例超过 1.5；`--teacher it2i`（先换一次条件再交给 `c_tail`）高频 **1.70**、网格 1.51、48 例里 44 例更糙。全量 224 例上是 1.85。再往上求逆就是 3.12。**换一次条件的画质代价约 1.8 倍高频，这个数现在是配对照出来的。**
2. **代价和收益都在同一张表上。** text 臂语义通过 31/48（65%），it2i 臂 174/224（78%）。也就是说，**现在用 1.8 倍纹理换来了 13 个点的语义通过率**，两条臂都不对：一条没有场景接地，一条有接地但把画质付掉了。
3. **`stage2` 没有额外作恶，它只是忠实地复现了标签的粗糙。** 学生输出 1.77，v5 标签 1.85，同一量级；而且到原生完稿的 L1 位移没有变大（0.070 vs 0.075）。"更糙"没有换来"改得更多"。
4. **机制是状态空间 L2 损失看不见尾段的吸引域。** 让状态在 L2 上位移变大，最便宜的方向是注入高频——逐块独立、不需要长程一致；尾段会把这份高频当信号保留（`x_eff` 对候选只有 1.11 倍高频、L1 0.039）。单步 `b-a` 损失完全不包含"这个状态会不会被 `c_tail` 接住"这一项，所以它没有理由避开这条路。
5. **语义通过与画质合格一直是两件事。** 51/51 记录都是 `pending_review=true`，35 例"通过"没有一例经过画质判定；`hf_effective / hf_parent` 早就写在记录里，只是没当门禁。v5 的 174 条"通过"是同一个问题：粗糙度在通过样本（1.85）与拒绝样本（1.75）之间没有差别。

由此，下一轮验收加一条硬门禁：**训练与评测都报 `hf_eff/hf_src`，超过约 1.5 即判画质不合格**。它同时是"以作品定义正确答案"的验证指标：如果换成图像空间两侧损失后这个比值仍然往上走，说明新目标只是把买噪声的位置从状态换到了别处。

## 6. 反演的新结果与当前选择

### 6.1 离散不动点反演没有成为可靠方案

离散逆尝试求解与部署 Euler 完全相同的一步关系。当前阻尼 Picard 在探测案例上表现为：增加迭代，结果反而恶化。

| 迭代次数 | 阻尼 | 节点残差 | 整段最大残差 | 前向往返 L1 | 报告的状态幅值 |
|---:|---:|---:|---:|---:|---:|
| 4 | 0.60 | 8.4e-4 | 2.6e-2 | 0.119 | 0.89 |
| 8 | 0.60 | 3.0e-3 | 2.8e-2 | 0.191 | 1.36 |
| 16 | 0.60 | 8.1e-3 | 4.0e-2 | 0.193 | 2.62 |
| 32 | 0.60 | 1.2e-2 | 7.0e-2 | 0.302 | 5.11 |
| 4 | 0.35 | 7.5e-4 | 2.6e-2 | 0.078 | 0.69 |

决定：默认使用 `reverse_heun`，不继续把增加 Picard 迭代作为当前生产方向。探测脚本为 `scripts/probe_inversion.py`。

这证明当前求解方法在探测案例上不可靠。它不能判定目标状态不存在，也不能量化 Heun 与 Euler 不匹配贡献了多少误差。残差表示求解精度，不表示图像是否可达。

### 6.2 配对 margin 保留为诊断，不作为新验收门

用户用旧缓存的重建图分析了 60 条记录：

| 量 | 中位数 |
|---|---:|
| 接续图到目标图的 L1 | 0.179 |
| 接续图到源图的 L1 | 0.259 |
| 源图与目标图之间的 L1 | 0.128 |
| 两个接续距离之差，即配对 margin | +0.065 |

60/60 条接续结果更接近目标。margin 的第 25、75 百分位分别为 +0.023、+0.124。margin 中位数按逐条差值统计，不要求等于两个距离中位数之差。

这些数字说明目标相对接近度为正；不能进一步当作“语义正确”或“沿正确方向走过头”。例如背景颜色接近目标、物体却扭曲，也会得到正 margin。

决定：保留该指标，不用 `margin_fraction=0.25` 重新定义可用标签，也不因此给 I 设置 10%–15% 的训练比例。I 本轮暂不进入主训练。

`L1=0.08 / LPIPS=0.20` 是早期未校准筛选值；模型自生成图像的往返 LPIPS 中位数 0.224 也是当前方法的测量，二者都不视为普遍的可达性界限。

## 7. 下一批 R-edit 怎么判合格

生产顺序固定为：

```text
真实父状态 a 和预览 P
  → 根据 P 指定短编辑指令与完整目标条件
  → 用同条轨迹的原生完稿图生成一次候选目标 x_edit
  → 在实际尾段条件下反演得到 b
  → 冻结原生尾段从 b 生成 x_eff
  → 验收 x_eff 的编辑、保留和画质
  → 进入训练清单
```

### 显式编辑：既要改成，也要保住其他内容

- `edit_questions`：只描述本轮要求改变的内容。
- `preserve_questions`：描述未要求改变的内容，去掉与本轮修改冲突的旧要求。
- `edit_needed`：实际源图尚未满足全部编辑题。
- `edit_complete`：实际接续图通过全部编辑题。
- `protected`：源图原本已经通过的保留题。
- `broken`：这些受保护要求中，接续后不再通过的题。

语义通过条件：确实需要编辑、编辑全部完成、没有破坏受保护要求。再由画质验收确认形体与纹理合格。

### 自纠偏：修正原提示中的失败项

父条件和尾段条件都用 `c_raw`。相对实际源图，至少修好一题，原本通过的题不被改坏；再确认成图质量。

显式编辑的尾段使用更新后的完整 `TARGET`。请求、目标图、反演、接续必须绑定同一条父轨迹和实际尾段条件。
