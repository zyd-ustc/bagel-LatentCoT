# 数据方案与构建 (Data Pipeline)

本文档介绍等时状态流的数据分类、标签构造原理、质量门禁与生产流水线。

---

## 1. 数据体系通俗解释 (L / I / R 是什么)

在生成状态空间做编辑，最核心的问题是：**学生从哪里拿到训练输入状态 $a$ 和监督目标 $b$？**

```
              ┌── L 数据 (Linear Pair)   : 现成图像对 + 同步加噪 (基础编辑能力预训练)
训练数据来源 ──┼── I 数据 (Inverted Pair) : 外部图数值求逆 (已证实破坏画质，彻底淘汰)
              └── R 数据 (Real Trajectory): 真实文生图轨迹产生的状态 (真实入口适配)
                     ├── R-keep : 真实前向态，目标 b = a (学习保持原图合理结构)
                     └── R-edit : 真实前向态，目标 b 接续至修改后的图 (学习精准变轨)
```

| 类型 | 来源与构造方式 | 作用与优缺点 | 现行状态 |
|---|---|---|---|
| **L 数据**<br>(Linear Pair) | 现有高质量配对图 $(x_{\text{src}}, x_{\text{tgt}})$，混入同一份随机噪声：<br>$a = (1-t)\sigma\varepsilon + t x_{\text{src}}$<br>$b = (1-t)\sigma\varepsilon + t x_{\text{tgt}}$ | **优点**：数据量大、语义清晰、易于训练基础编辑能力。<br>**缺点**：状态不在真实文生图的轨迹上。 | **保留**<br>用于 Stage 1 预训练和 Stage 2 防遗忘回放（占比约 10%~15%） |
| **I 数据**<br>(Inverted Pair) | 拿现成的编辑后终图，通过逆向 ODE 积分算子 $\Psi$ 强行反推回 $t=0.36$ 的带噪状态 $b$。 | **重大缺陷**：外部图像不在原生流形上，逆向求解困难且严重失真，导致成图高频能量暴增 2.55 倍（满屏碎斑）。 | **彻底淘汰**<br>禁止进入主轮训练 |
| **R-keep** | 让原生文生图正常跑完，截取 $t=0.36$ 的状态 $a$；**直接将标签设为 $b=a$**。 | **不可或缺**：教模型学会“如果当前画面不需要改动，就保持原样直通，不要画蛇添足”。 | **主力保留**<br>全量使用（~6,500 条，占比 30%~75%） |
| **R-edit** | 真实前向轨迹状态 $a$，通过**同噪声纯文本耦合**生成配对的变轨状态 $b$。 | **核心攻坚数据**：真实入口 + 干净画质（高频比仅 1.07），教模型在真实生成中途撤销缺陷、新增内容。 | **核心主力**<br>现行最优构造，配额约 15%~55% |

## 2. 关键突破：R-edit 标签的进化史

如何让 R-edit 既能学到明确的编辑，又不会污染画质？项目历经三代探索：

1. **第一代：外部编辑 + 逆向反演（失败）**：
   - 用第三方图像编辑器改好终图，再数值反演求逆取 $b$。实测高频能量暴涨至原生完稿的 **2.55 倍**，出现荧光色与重度碎纹，严格门禁下 8000 条仅 17 条通过（0.2%），被判否定。
2. **第二代：图像条件教师（IT2I）引导（不划算）**：
   - 教师看源图或预览图在多模态条件下去噪得到 $b$。虽然编辑完成度较高，但高频能量仍高达 **2.0 倍**，且降低 CFG 无法缓解。
3. **第三代（现行推荐）：同噪声纯文本耦合分支（Pure-Text Coupled Forward）**：
   - 从**同一份随机噪声 $\varepsilon$** 出发，底座同时跑两条原生流：
     
     $$a = \Phi^{c_{\text{parent}}}_{0 \to t}(\varepsilon), \qquad b = \Phi^{c_{\text{tail}}}_{0 \to t}(\varepsilon)$$
     
   - 两条轨迹在动力学上完全天然相容，不经过任何反演，**高频代价仅 1.07 倍**，成图极其干净自然！

---

## 3. 高质量标签的三项请求侧约束

纯文本耦合要在不破坏画面的前提下改对内容，必须配合**三处严格的提示词与问题约束**（使配对通过率从 37% 跃升至 78%）：

1. **目标描述（`TARGET`）最小改写**：
   - 目标描述只能修改发生变动的局部从句，禁止天马行空地重写视角、光影或服装。
   - **门禁**：与源场景词汇重合度低于 50% 的请求直接剔除。
2. **编辑题（`edit_questions`）严格唯一且源图必假**：
   - 每次编辑**只针对 1 个明确要求**（如“桌上是否有 5 个杯子”）；
   - 该要求在源图上**必须为假**（源图若本来就是对的，则说明该编辑毫无意义，直接舍弃）。
3. **保留题（`preserve_questions`）源图必真**：
   - 从原提示词拆解出的保留约束，在源图上**必须已实际通过**；
   - 在编辑后，这些保留题必须全部继续通过，确保“只修错误、不改坏正确内容”。

## 4. 几何与工程质量门禁

### 4.1 共同场景视野对齐 (Geometry Alignment)
源图与目标图必须映射到相同的物理画布范围：
- 如果源图与目标图宽高比不同，直接缩放会导致局部编辑变成“整体变形或视角拉伸”。
- **规则**：宽高比差异必须 $\le 1\%$，不同比例必须声明裁切范围，否则直接丢弃。

### 4.2 RGBA 与色彩位深归一化
- 目标图像中的透明通道统一做白底 RGB 合成并归一化至 $[-1, 1]$，防止网络把透明度当作语义编辑来学习。

### 4.3 终图验收准则 ($x_{\text{eff}}$ 验收)
- 任何验收必须在**真实接续终图** $x_{\text{eff}} = \Phi^{c_{\text{tail}}}_{t \to 1}(b)$ 上执行，而不是在任何中间候选图 $x_{\text{edit}}$ 上。
- 只有当 $x_{\text{eff}}$ 满足 `编辑完成 + 保留未破坏 + 高频比 ≤ 1.30` 时，才允许标记为合格训练样本。

## 5. 数据生产与流水线命令

### 5.1 生产显式编辑请求 (Step 1)
根据真实轨迹的预览图生成符合三大约束的编辑请求清单：
```bash
python scripts/build_explicit_requests.py \
  --cache "$DATA_DIR/r_v3" \
  --output "$DATA_DIR/explicit_v5/requests.jsonl" \
  --limit 400 --shard-index 0 --shard-count 8
```

### 5.2 生产耦合配对数据 (Step 2)
调用纯文本耦合分支生成状态与预览：
```bash
python scripts/prepare_coupled.py \
  --requests "$DATA_DIR/explicit_v5/requests_all.jsonl" \
  --source-cache "$DATA_DIR/r_v3" \
  --output "$DATA_DIR/coupled_v5_text" \
  --teacher text \
  --shard-index 0 --shard-count 8
```

### 5.3 合并训练缓存与白名单过滤 (Step 3)
按角色白名单合并 R-edit 与 R-keep，杜绝脏数据混入：
```bash
python scripts/build_training_cache.py \
  --caches "$DATA_DIR/coupled_v5_text" "$DATA_DIR/r_v3" \
  --allow "$DATA_DIR/coupled_v5_text=R_edit" \
  --allow "$DATA_DIR/r_v3=R_keep" \
  --roles R_keep \
  --output "$DATA_DIR/train_v5" \
  --shards 8
```

### 5.4 训练前数据硬闸门检验 (Step 4)
开训前必须使用真实运行时进行抽样协议校验，测试不通过禁止开训：
```bash
python scripts/verify_training_data.py \
  --model "$MODEL_DIR" \
  --source "$SOURCE_DIR" \
  --config configs/u15_isochronic_state/stage2_v5.json \
  --native "$DATA_DIR/train_v5" \
  --draws 6
```
