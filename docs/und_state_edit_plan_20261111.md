# UND 条件驱动的中间态编辑规划

日期：2026-11-11。状态：下一轮数据、训练与推理方案，尚未实施。适用底座：当前仓库中的 SenseNova-U1.5 MoT。

目标：让 GEN LoRA 学会使用冻结 UND 提供的场景与修正信息，在固定生成时间转移当前状态，并通过冻结的原生尾段完成语义编辑。终图监督覆盖完整执行路径，同时学习编辑结果与内容保持。

| 学习对象 | GEN 全层 rank-64 LoRA 与现有 edit_s_embedder |

## 设计依据与事实边界

本地 train.py 的 R 终端路径不使用目标状态 b。最新 docs/data.md 进一步明确，v2 数据采用完整 IT2I 终图，state_b=None。这是终图蒸馏设计的主动选择，不能再把它表述为目标轨迹监督遗漏。已有真实父状态与预览继续使用；无需重建反演目标状态。

截至本次检查，本地 terminal.py 仍使用差分分位数掩码，data.py 与 train.py 没有把 edit_box 传到损失。docs/closed_loop_diagnosis.md 所述补丁需要与实际运行版本核对；本方案把区域监督列为待实现项。

以下推断不作为设计前提：

- L1 风险的逐坐标最优解一般是条件中位数，条件均值对应平方误差。像素对齐误差可能诱发结构折中，但残影的具体成因尚需对照。
- 60% 分位数附近以上的像素可进入软掩码，不等于固定 40% 画面被赋予全权重。平滑、并列值和差分分布都会影响有效面积。
- 当前高频参考是 x_source，默认存在 0.75 至 1.15 的双侧软惩罚；它不是相对教师图的硬上限。
- L_edit 走单步流匹配，不展开 T2I 尾段。训练样本占比不等于梯度贡献占比。
- 原始 prompt 在修复任务中已经描述目标。目标条件合法存在；是否绕过修正指令需要在同条件对照中测量。
- 多时刻共享目标终图不构成数学矛盾，t=0.50 也不是不可编辑的物理边界。先固定 t=0.36 是为统一部署与训练任务。
- 混合 L/R 可能存在优化干扰，不能仅由两类损失形式不同就推出梯度冲突。移除 L 是为了让本轮真实状态适配具有统一目标。

## 架构与训练信号

设 c_src 为生成父轨迹的文本，a_t 为真实父状态，P_t 为从该状态副本生成的前瞻预览，e 为编辑指令，c_goal 为期望终图描述，p 为保留要求。

冻结 UND 编码条件：

$$
K^{\mathrm{UND}},V^{\mathrm{UND}}=U_0(P_t,e,c_{\mathrm{goal}},p).
$$

GEN 图像 token 经适配后的查询与后续计算使用这些 KV。所有原生参数冻结，更新 GEN LoRA 与编辑进度嵌入。论文可表述为学习使用 UND 条件的状态转移，不能表述为重新训练 UND 的观察或诊断能力。

保留现有速度形式：

$$
b_0=\operatorname{sg}[H_0(a_t,t;P_t)],\qquad
u_\theta(q_s,t,s)=t\,[H_\theta(q_s,t,s;K^{\mathrm{UND}},V^{\mathrm{UND}})-b_0].
$$

$$
q_0=a_t,\qquad q_{k+1}=q_k+\frac18u_\theta(q_k,t,k/8),\qquad \hat b_t=q_8.
$$

冻结原生 T2I 接续：

$$
\hat x=F_0(\hat b_t,t\rightarrow1;c_{\mathrm{goal}}).
$$

梯度从终图损失经过完整原生尾段与 8 步编辑到达 LoRA。冻结尾段权重，同时保留它对输入状态的导数；不能用 no_grad 包住这段训练前向。UND 条件与固定基准 b0 可以停止梯度。

8 步属于一次反馈后的编辑积分，中间不重新运行 UND 诊断。是否增加反馈轮次不属于本轮改造。

关闭 LoRA 与绕过编辑器是不同控制：现有 H_joint-H_image 参数化即使关闭 LoRA，也未必产生零位移。无编辑基线应显式从 a_t 直接接续。

## 数据协议

### 三种任务共享一个目标条件定义

| 任务 | 父轨迹文本 c_src | 目标 c_goal | 指令 e |
| --- | --- | --- | --- |
| R_repair | 原提示词 | 原提示词 | 修复指定、确实存在的错误 |
| R_active | 原场景描述 | 根据用户编辑更新后的目标描述 | 明确的目标变化 |
| R_keep | 原提示词 | 原提示词 | 保持当前场景 |

UND prefix 与原生尾段使用同一个 c_goal。训练和部署都执行这条规则。主动编辑不能把尾段换成与新目标冲突的 c_src；例如把红球改蓝后仍让尾段生成红球，会人为制造矛盾监督。

修复任务禁止为了解决计数失败，把原 prompt 偷换成更容易完成的目标。主动编辑部署需要同时提供或构造 c_goal，这属于交互编辑接口，不能用于替代修复主实验。

### 样本生成

1. 用冻结原生模型生成父轨迹，缓存 t=0.36 的真实 a_t、对应 P_t 与同轨迹原生终图 x_src。
2. 对照 c_goal 检查 P_t 与 x_src。主修复池取预览中可识别、在正常接续终图中也未解决的错误，避免把自然接续会修复的现象大量当作正修复样本。
3. 生成具体指令，注明对象、目标数量或目标关系。计数指令给目标数量，空间指令明确主体与参照物。以单一关系或单一对象组为主；多对象组指令逐项列出验收目标。
4. 冻结原生 IT2I 读取 x_src 与指令生成候选终图 y。继续使用完整 IT2I 教师；教师无需与学生走同一条中间轨迹。
5. 验收 y 是否完成指定指令、保留已正确内容、具有完整形体。像素差异用于定位异常重绘，不承担语义验收。
6. 标注允许变化区域 M，保存训练记录。教师图在 M 外发生显著无关重绘的样本退出主训练池，不用提高保持损失权重硬拉回来。

从 x_src 观察到的错误若在 P_t 中无法辨认，不进入这一轮以预览信息为条件的核心修复池。训练输入不包含 x_src、教师 y 或生成教师时的隐藏信息；它们只用于离线构造与监督。

R_keep 必须保留真实父状态 a_t 与它的原生终图 x_src。不能把 x_src 重新线性加噪后称为真实历史态保持样本。即使 keep 样本有直通路径，训练时也必须强制经过编辑器，才能教会被调用时保持内容。

### 采样配额

角色配比按训练抽样设置为 repair/active/keep = 60/30/10，不能由教师产量决定。非 keep 样本按目标需求分层：计数 40%、空间关系 40%、属性及其他局部修改 20%。

计数再均衡数量增加与减少，防止删除成为默认解。空间覆盖左右、前后和上下关系，保留部分包含多个对象的构图。这里按语义目标分类，add/remove/move 作为实现动作记录，不再用 remove=40% 作为主任务配额。

这些比例针对本轮计数与空间修复目标。现有 11,065 条按新协议复核与重采样，只补缺少的目标类型；不因删除样本更容易合格而用它补足修复份额。

按父轨迹和 prompt family 划分训练与验证。同一父轨迹的全部指令和状态留在同一集合。已有被反复查看的 Hard48 用于开发诊断，另固定未参与方案选择的测试集承担当次结果报告。

### 区域的含义

M 表示允许变化的空间支撑范围，不要求新增分割网络。可由多个框的并集提供，记录在原图坐标系并使用与图像一致的裁剪、缩放。

| 修改 | M 必须覆盖 |
| --- | --- |
| 删除 | 被删对象及其需要重建的遮挡区域 |
| 添加 | 新对象预期位置及合理遮挡区域 |
| 移动 | 原位置与目标位置，包含需要改变的遮挡和阴影 |
| 计数修正 | 需要重新组织的对象组；必要时允许整个局部布局变化 |
| 属性修改 | 对应对象区域 |

单个旧位置 edit_box 不足以监督移动。参照物可以出现在感知裁剪的上下文中，同时在 M 外接受保持监督。

默认不进行教师背景硬拼接。拼接不能自动修正遮挡、阴影和接触关系。采用分区域损失直接表达编辑和保持；教师目标与原图在边界和区域外需要具有可兼容的场景结构。

### 最小记录

uid、source_family、prompt_family、split、role、semantic_task、operation、c_src、c_goal、edit_instruction、preserve、time、state_a、preview、x_source、x_teacher、edit_regions、edit_questions、preserve_questions。

保留当前字段时，parent_condition 对应 c_src，tail_condition 对应 c_goal，无需为概念统一重复保存一份文本。edit_regions 可由现有 edit_box 的单元素列表表示，但空间任务允许多个区域。state_b 保持空，不将完整 IT2I 终图重新伪造为同噪声目标状态。

## 终图训练目标

采用一个区域化终图重建目标：

$$
\mathcal L_{\mathrm{terminal}}=
D_{\mathrm{LPIPS}}(C_B(\hat x),C_B(y))
+0.1\,\ell_1^M(\hat x,y)
+1.0\,\ell_1^{1-M}(\hat x,x_{\mathrm{src}}).
$$

其中 B 是同时包含编辑区域及必要关系上下文的裁剪框，C_B 对预测与目标执行同一裁剪。两项像素损失按各自有效区域面积与通道数归一化。0.1 与 1.0 是本轮起始权重，试点确认后固定。

- LPIPS 使用冻结 VGG 版本，监督对象外观和局部结构差异；它不直接保证计数正确。
- 弱像素项补充颜色、位置和局部对应。
- 区域外保持项以原生终图为参照，不追随教师背景漂移。
- keep 样本设置 M=0，跳过空编辑区域损失，使用整图原生终图重建。

LPIPS 对完整裁剪调用，不把图像乘掩码生成黑底边缘再计算。裁剪包含关系参照物；教师在这部分上下文的无关变化必须在数据验收时控制。

训练 LPIPS 路径需要对预测图可微。当前 loss.py 的 perceptual_distance 有 no_grad、render 与 float 转换，是评测路径，不能直接复用。冻结 VGG 参数，保留对预测图输入的梯度；像素项使用未截断的输出，LPIPS 使用匹配官方 RGB [-1,1] 接口的显示输入，显示裁剪的饱和区域仍由像素项提供梯度。

默认移除全局高频惩罚，不将它扩展成多套区域频域项。LPIPS 是本轮新增的唯一特征损失，不叠加 DINO、CLIP、语义奖励或额外状态锚点。

不增加 R state loss：当前 v2 没有可用教师 b，终图路径已直接训练编辑器生成能够接续的状态。终图监督提供质量学习信号，实际的无重影与形体完整性由终图验证判定，不能由损失形式承诺。

参考：[LPIPS 官方实现与可微优化说明](https://github.com/richzhang/PerceptualSimilarity)。

## 训练安排

| 项目 | 本轮默认值 |
| --- | --- |
| 初始化 | Stage 1 step_003607；重置优化器 |
| 适配范围 | 当前 GEN 全层 rank-64 LoRA、edit_s_embedder |
| 时间与积分 | t=0.36；8 步完整等时编辑；完整冻结尾段 |
| CFG / 原生采样 | 保留当前 CFG=4 与原生采样协议 |
| 训练角色 | R_repair 60%、R_active 30%、R_keep 10% |
| L_edit | Stage 2 权重 0；作为固定能力验证集保留 |
| 优化器 | 沿用 AdamW、betas=(0.9,0.95)、eps=1e-8、weight_decay=0 |
| 学习率 | 1e-5，warmup 100 步，余弦下降至 2e-6 |
| 全局 batch | 64，沿用每卡一个样本 |
| 梯度裁剪 | 1.0，沿用现有设置 |
| 主预算 | 1200 步；150、300、600、900、1200 步验证 |

移除 L 后，L 的加载、训练数据版本记录和 sampler 初始化必须允许没有 linear manifest。不能只把权重改成零却继续要求加载 L 资源。

读取时间固定不应意外改变原生采样网格。沿用当前数据对应的 parent/tail 网格，将训练时刻采样与网格节点分开；如果确实修改网格，需要同步重产父状态、预览和原生终图。

先做 32 个已人工确认训练样本的学习试点，覆盖计数增减、空间移动、属性和 keep，最多 150 步，记录初始化与训练后的同状态终图。这一步验证整条监督能否教会给定修改，不承担泛化结论。试点从 Stage 1 单独启动，主训练重新从同一 Stage 1 初始化。

主训练复用验收合格的数据并补齐缺类，固定一个按任务分层的 128 条开发验证集；最终测试另行冻结。不能只凭 rank 0 单样本日志判断各角色趋势：损失记录按角色跨 rank 汇总 sum/count，同时保存语义与画质验证结果。

检查点选择按指令完成、已正确内容保持与可见伪影联合检查，不按训练总损失最小选模型。至少保留初始化、旧 step_001200 与新训练检查点的匹配结果。

## 推理协议

1. 原生模型按 c_src 与给定种子运行到 t=0.36，得到 a_t。
2. 在状态副本上生成 P_t。冻结 UND 根据 P_t 与目标描述定位可执行错误；诊断器的输入不包含未来原生终图。
3. 闭环修复保持 c_goal=c_src，生成 e 与 p。显式交互编辑使用用户变更后的 c_goal。
4. 无需编辑则从 a_t 原生接续。存在编辑指令时，UND 生成条件 KV，GEN LoRA 完成 8 步等时状态转移。
5. 关闭适配分支，由冻结原生 T2I 在 c_goal 下完成剩余生成。

第一轮部署维持一次诊断、一次编辑、一次接续。无需重新采样主轨迹噪声，也不回退生成时间。

M、教师图 y、未来原生终图 x_src 只用于训练和评测，不加入部署模型输入。论文图中应将这些监督信息与推理路径明确分开。

## 验证与论证职责

### 执行能力

固定 a_t、P_t、c_goal、e 和尾段网格，比较：

| 对照 | 作用 |
| --- | --- |
| a_t 直接在 c_goal 下接续 | 排除仅改变尾段条件带来的效果 |
| Stage 1 初始化编辑器 | 测量真实状态适配的增益 |
| 旧 step_001200 | 比较新的数据与监督组合 |
| 新检查点 | 主结果 |

主判据是指定修正全部完成的比例；并列报告原本正确的要求保留率、形体破坏或重影案例比例。保留区像素差仅作保持的辅助量，不以高频比替代画质，也不以 LPIPS 替代计数和空间正确性。

### UND 条件的使用

在相同 a_t 与 c_goal 下，对固定验证子集分别省略编辑指令，或替换为预先选定的同类错配预览；其余输入不变。与正确条件比较语义完成及变化位置，并在 Stage 1 与新检查点上使用同一组干预。

这些实验检验条件依赖及其训练前后变化。错配引起图像破坏本身不能证明有用的读取；需要正确条件提高相应编辑成功，并观察干预导致的任务相关变化。若完整目标 prompt 已给出相同信息，省略 e 后不变不等于没有使用 UND，应分别解释图像条件和指令条件的职责。

### 自动闭环

执行器通过确认指令验证后，再在完整固定 prompt 集上比较自动诊断闭环与原生直接生成。两者均评终图。开发数据可筛选持续错误；正式闭环评测必须覆盖自然接续可修复、无需修复及诊断误触发的样本，不能只报告有利编辑子集。

主报告使用与训练筛选独立的判分流程，并对计数、空间及画质分歧样本进行盲审。完整 prompt 满足率和指定编辑完成率分开，避免要求教师对一条局部指令承担所有未指定错误。

## 论文主张

方法主线：冻结 UND 将中途预览与修正意图编码为条件，GEN LoRA 将这些条件转化为生成中间态的定向变化，原生尾段把变化完成为最终图像。

终图监督是训练这个转移算子的方式。区域标注和感知重建服务于指令完成与内容保持，不作为额外架构创新包装。

最硬的结果应来自同状态、同尾段条件下的语义修正收益，并由 UND 条件干预和终图质量对照解释。固定时间、冻结底座与复用父轨迹是方法属性；质量、成功率和效率的优势需要对应实验结果。
