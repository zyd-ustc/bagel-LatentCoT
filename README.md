# BAGEL-LatentCoT

在冻结BAGEL上学习独立Memory，连接理解专家与生成专家的语义读写。

Memory从中性文本表示开始，经连续理解层读取文本或生成状态，形成逐层语义条件。低秩残差负责表达与读取适配，BAGEL保留原生专家、注意力和生成结构。

理解侧将Memory读出为caption，生成侧将Memory融入图像生成条件。更新后的生成状态再进入Memory，形成同一采样状态内的信息反馈；最终速度推动图像latent继续演化。
