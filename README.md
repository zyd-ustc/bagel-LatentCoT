# Bagel Latent CoT: 目标驱动纠偏

在 Ascend NPU 上使用冻结的 SenseNova-U1.5 模型实现文生图轨迹内纠偏。

模型从纯文本输入开始生成。冻结的理解模块检查中途生成的前瞻草图。如果各项检验通过，生成过程继续沿原轨迹前进。如果发现缺陷，系统回退至确定性的历史状态。纠偏器在设定时间窗口内修正速度场，随后由原生模型完成尾段生成。

训练过程分为两个阶段：第一阶段使用高质量编辑目标监督局部的速度残差；第二阶段从真实历史状态展开积分，通过冻结的原生尾段监督最终生成的完整图像。第二阶段在前向过程中使用部署细网格积分，在反向过程中使用粗网格提供代理梯度。

## 安装

在配置好 PyTorch 与 torch_npu 的环境中安装：

```bash
pip install -e .
```

系统主入口为命令行工具 `u15-target-correction`，支持 `trace`、`train`、`sample` 和 `judge` 四项子命令。运行外部评审时需要安装 `openai` 包。
